对已有研究的汇总

12种动机
#

主维度 关键词 子成分 详细描述
动作 (Action) “Boom!” 破坏 (Destruction) 享受混乱、爆炸、枪支和毁灭带来的快感。喜欢《使命召唤》、《战地》等游戏。
刺激 (Excitement) 追求快节奏、高强度的肾上腺素飙升体验，喜欢惊喜和快速反应。如《光环》、《街霸》。
社交 (Social) “一起玩” 竞争 (Competition) 享受与其他玩家的对抗、决斗、比赛或排名。如《英雄联盟》、《星际争霸》。
社区 (Community) 喜欢与他人合作、聊天、组队，将游戏视为维护社交网络的方式。如《传送门2》、大型公会活动。
精通 (Mastery) “让我思考” 挑战 (Challenge) 追求高难度、技能磨练和坚持。愿意反复失败以掌握游戏机制。如《黑暗之魂》、《osu!》。
策略 (Strategy) 享受深思熟虑的决策、规划和资源管理。喜欢战术布局和长期战略。如《文明》、《XCOM》。
成就 (Achievement) “我要更多” 完成 (Completion) 渴望完成所有任务、收集所有物品、解锁全成就。追求“全收集”和“完美通关”。
力量 (Power) 追求角色数值成长、获取最强装备和技能升级。享受从弱变强的过程。如《魔兽世界》、《暗黑破坏神》。
沉浸 (Immersion) “从前…” 幻想 (Fantasy) 渴望成为另一个世界中的另一个人，享受身临其境的替代现实体验。如《上古卷轴》、《辐射》。
故事 (Story) 重视复杂的剧情、多维度的角色背景和叙事深度。低分者倾向于跳过对话。如《质量效应》、《最后生还者》。
创造 (Creativity) “如果…?” 设计 (Design) 希望通过自定义外观、建造或表达个性来展现自我。如《模拟人生》、《动物森友会》。
发现 (Discovery) 好奇心驱动，喜欢探索未知、测试边界、实验非预期玩法。问“如果这样做会怎样？”。如《我的世界》、《塞尔达传说》。

动作-社交动机
#

  • 动作-社交类型注重即时性和肾上腺素的刺激。那些在这些动机上得分高的玩家希望自己能感到兴奋，无论是通过游戏本身还是与其他玩家互动。
动机 光谱维度 低分偏好与代表游戏 (Low) 高分偏好与代表游戏 (High)
破坏
(Destruction)		 世界观基调
(Entropy vs Enduring)		 持久/宁静 (Enduring)：偏好田园、宁静、无武器/血腥的G/PG级内容，追求岁月静好。
🎮 《雷顿教授》《神秘岛》《动物森友会》《牧场物语》		 混乱/熵 (Chaotic)：热爱枪支、爆炸、大屠杀、血腥及可破坏环境，享受纯粹的毁灭快感。
🎮 《光环》《使命召唤》《命运2》《战地》
刺激
(Excitement)		 节奏与刺激度
(Calm vs Thrilling)		 平静 (Calm)：偏好回合制、可随时暂停、放松、可预测且低视觉刺激的游戏。
🎮 《文明》《神秘岛》《猎户座之主2》《欧陆风云2》		 惊险 (Thrilling)：追求快节奏、动作导向、充满惊喜和肾上腺素飙升的体验。
🎮 《CS:GO》《使命召唤》《任天堂明星大乱斗》
竞争
(Competition)		 对抗性质
(Non-Adversarial vs High Conflict)		 非对抗性 (Non-Adversarial)：拒绝竞争，不喜欢针对人类玩家的排名或决斗，追求和平体验。
🎮 《神秘岛》《回家》(Gone Home)《龙腾世纪2》		 高冲突 (High Conflict)：热爱对抗、竞技场、决斗、比赛、排行榜和排名系统。
🎮 《英雄联盟》《Dota 2》《使命召唤》《CS:GO》
社区
(Community)		 社交依赖度
(Independence vs Teamwork)		 独立 (Independence)：偏好单人游戏、可单刷的任务，希望完全掌控游戏进程，不依赖他人。
🎮 《乐高哈利波特》《农场英雄传奇》		 团队合作 (Teamwork)：喜欢组队、聊天、社交互动和协作，将游戏视为共享体验。
🎮 《命运》《战地》《最终幻想14》《彩虹六号》

动作
#

  • 动作得分高的玩家气势汹汹，喜欢纵身跃入硝烟战场中，享受震撼人心的视觉效果。动作得分低的玩家则更喜欢节奏平缓、岁月静好的游戏。
1. 破坏
#
  • 在破坏要素上获得高分的玩家便是混乱与毁灭的化身。他们乐于运用一切工具狂轰滥炸、制造混乱。他们喜欢使命召唤、战地这种拥有大量枪械与爆炸物的游戏。而如果不小心进入了模拟人生这样的游戏，他们就是想方设法整死自己的模拟小人的那种人
2. 刺激
#
  • 在刺激要素上获得高分的玩家喜欢节奏明快的游戏方式、肾上腺素飙升的游戏体验。他们想要出乎意料的，充满动作元素与兴奋感的玩法，并从极限操作中获取正反馈。不止是光环这种第一人称射击游戏拥有这种游戏体验，街头霸王、 不义联盟，或者节奏奔跑者这样活力四射的平台跳跃游戏也一样拥有

社交
#

  • 社交得分高的玩家喜欢与他人互动，无论是互帮互助还是一决雌雄。社交得分低的玩家则更喜欢独立的单人游戏体验。
3. 竞争
#
  • 在竞争要素上获得高分的玩家喜欢互相竞争的游戏方式，在决斗、比赛或团队赛中与其他玩家一争高下。诸如星际争霸、英雄联盟或魔兽世界里的PVP战场都是这种竞争型游戏。但是竞争也并不意味着只有挑起争斗；也会有竞争型玩家想成为公会里最好的辅助，或是在微信朋友圈小游戏里刷出比朋友更高的分数、去偷朋友的蚂蚁森林能量
4. 团体
#
  • 在团体要素上获得高分的玩家喜欢合作社交、聊天组队的游戏方式。这可以是和朋友玩传送门2，也可以是在聚会上玩马里奥赛车，或是在网络游戏中加入一个大型公会。他们喜欢成为团队中的一员，与其他人齐心协力完成共同目标。对于他们来说，游戏是维持他们社交网络不可或缺的一部分

精通-成就动机
#

  • 精通-成就关乎冷静、长期的游戏玩法。它追求渐进和累积的机制，观察城市/农场随着时间不断发展。
动机 光谱维度 低分偏好与代表游戏 (Low) 高分偏好与代表游戏 (High)
完成
(Completion)		 目标来源
(Self-Driven vs Task-Oriented)		 自我驱动 (Self-Driven)：偏好沙盒/开放玩法，自己决定目标，不依赖系统指派任务。
🎮 《边缘世界》(RimWorld)《坎巴拉太空计划》《城市：天际线》		 任务导向 (Task-Oriented)：喜欢完成系统任务/成就，收集星星、奖杯和所有收集品。
🎮 《最终幻想》《乐高次元》
力量
(Power)		 成长曲线
(Flat vs Progression-Based)		 扁平成长 (Flat Progression)：角色开局即完全体，数值静态，强调公平的竞技环境，无需“肝”。
🎮 《ICO》《Her Story》《80 Days》《漫漫长夜》		 基于成长 (Progression-Based)：享受从弱变强，喜欢刷怪升级、提升数值和强化装备/法术。
🎮 《魔兽世界》《暗黑破坏神3》《英雄联盟》
策略
(Strategy)		 决策复杂度
(Spontaneous vs Contemplative)		 随性/反应式 (Spontaneous)：认知负荷低，时间视野短，凭直觉和反应游玩，无需深思熟虑。
🎮 《模拟人生》《马里奥赛车Wii》《Covet Fashion》		 深思熟虑 (Contemplative)：需要深度思考、长远规划、权衡复杂决策及其后果。
🎮 《星际争霸2》《群星》《EVE Online》《欧陆风云4》
挑战
(Challenge)		 技能门槛
(Easy Fun vs Skill-Based)		 轻松乐趣 (Easy Fun)：上手快，技能门槛低，机制直观，没有基于技能的卡关挫败感。
🎮 《星露谷物语》《动物森友会》《Oxenfree》		 基于技能 (Skill-Based)：学习曲线陡峭，规则/操作复杂，追求挑战高难度Boss和硬核操作。
🎮 《Dota》《街霸5》《osu!》《大乱斗》

精通
#

  • 精通得分高的玩家喜欢具有战略深度和复杂性的高难游戏体验。技术得分低的玩家则更喜欢随心所欲地游玩，偏爱容易上手、容错率高的游戏。
5. 挑战
#
  • 在挑战要素上获得高分的玩家喜欢那些依赖于高超技术的游戏。他们坚持不懈地花时间磨练自己的技巧，以应对游戏中那些难如登天的任务与boss战。这些玩家总会挑战最高难度，不介意在黑暗之魂等游戏中反复去世，因为他们知道宝剑锋从磨砺出的道理。他们想要充满挑战的游戏体验
6. 谋略
#
  • 在谋略要素上获得高分的玩家喜欢在游戏中步步为营、谋定后动，享受作出选择后随之而来的后果。这些选择可能是要平衡资源、攻城略地、管理外交或制定策略。他们喜欢在XCOM或火焰纹章等游戏中运筹帷幄，也喜欢让自己的布局规划在诸如文明、城市：天际线或欧陆风云等游戏中实现

成就
#

  • 成就得分高的玩家乐于去花时间去肝，去积攒力量、收集稀有物品和收藏品。成就得分低的玩家则以风轻云淡的态度看待游戏成就，并不太在意游戏中的进展或得分。
7. 收集
#
  • 在收集要素上获得高分的玩家喜欢完成游戏的所有内容。他们试图完成每个任务，找到所有收藏品，并解锁全部隐藏地点。对于一些玩家来说，这可能意味着达成全成就，或解锁游戏中所有的角色/动作。对于在设计上获得高分的玩家，也可以是在游戏中收集服装和坐骑，比如魔兽世界
8. 力量
#
  • 在力量要素上获得高分的玩家在游戏世界中渴望力量。他们想要尽可能地变得强大，并寻求实现这一目标所需的物品装备。在角色扮演游戏和动作游戏中便是最大限度地提高属性，或者取得最强大的武器或奇物。力量和收集往往相辅相成，但有些玩家喜欢收集服装，并不在意力量；另一些玩家喜欢通过策略优化来获得力量，而不是肝

沉浸-创意动机
#

  • 沉浸-创意是关于最广义上的玩乐。它追求广阔而富有表现力的玩法风格，好奇心重，并且总是在测试游戏的边界。
动机 光谱维度 低分偏好与代表游戏 (Low) 高分偏好与代表游戏 (High)
幻想
(Fantasy)		 世界观构建
(Generic vs Deep Lore)		 通用/抽象 (Generic/Abstract)：背景抽象或通用，2D/复古画风，极少世界观铺垫，注重纯粹玩法。
🎮 《CS:GO》《街霸》《糖果传奇》《坦克世界》		 深度背景 (Deep Lore)：丰富的世界历史/传说，极具代入感的异世界，视觉沉浸感强。
🎮 《质量效应》《辐射》《龙腾世纪》《星战KOTOR》
故事
(Story)		 叙事结构
(Open-Ended vs Scripted Drama)		 开放式/无主线 (Open-Ended)：没有宏大叙事，NPC基础，提供一块“空白画布”让玩家自己创造故事。
🎮 《异星工厂》(Factorio)《模拟城市》《雷神之锤3》		 剧本化戏剧 (Scripted Drama)：精心编排的故事弧光，拥有大量具备动机和性格的立体角色。
🎮 《质量效应》《奇异人生》《女神异闻录4》
发现
(Discovery)		 未知元素
(Practical vs Curious)		 实用主义 (Practical)：规则完全透明，未知变量和隐藏互动极少，所见即所得。
🎮 《FIFA》《使命召唤》《麻将》《拼字游戏》		 好奇心驱动 (Curious)：热衷探索世界、寻找隐藏秘密/宝藏、测试物品交互和边界（“如果这样做会怎样？”）。
🎮 《上古卷轴》《塞尔达传说》《神秘岛》(Riven)
设计
(Design)		 个性表达
(Curated vs Customizable)		 固定/策展式 (Curated)：角色固定（即使风格化），极少或没有自定义外观的机会，接受开发者设定的形象。
🎮 《时空幻境》(Braid)《超级肉肉哥》《超级马力欧银河2》		 高度可定制 (Customizable)：强烈的自我表达欲，喜欢捏脸、装修房屋、收集大量皮肤/配饰。
🎮 《模拟人生》《激战2》《动物森友会》《上古卷轴OL》

沉浸
#

  • 沉浸得分高的玩家希望游戏具有有趣的人、事、物，以便他们真正沉浸另一个世界。沉浸得分低的玩家则更注重游戏机制，对游戏提供的叙事体验不太关心。
9. 幻想
#
  • 在幻想要素上获得高分的玩家希望在另一个世界中扮演另一个人。他们享受着成为异世界中的另一个自己那样的沉浸感，喜欢只为探索而去探索游戏世界。这些玩家喜欢诸如天际、辐射和质量效应这类的游戏，因为它们都拥有着设定丰满的异世界设定
10. 故事
#
  • 在故事要素上获得高分的玩家想要扣人心弦的故事情节，以及栩栩如生的人物。他们会花时间深入了解龙腾世纪和质量效应等游戏中人物的背景故事，喜欢最后生还者和生化奇兵等游戏中草蛇灰线、伏脉千里的游戏叙事。故事得分较低的玩家则会觉得对话和任务描述乏味，会尽可能想要跳过

创意
#

  • 创意得分高的玩家会不断试验，用自己的精妙设计来改造出满意的游戏世界。创意得分低的玩家玩游戏更脚踏实地，他们坦然地接受游戏世界的本来面目。
11. 探索
#
  • 在探索要素上获得高分的玩家时常会想“假如”。对他们来说，游戏世界是巧夺天工的器物，能够纵身其中，也能够尽情鼓捣。在网络游戏中，他们可能会游到海洋的边缘，看看会有什么事发生。在我的世界这样的游戏里，他们可能会测试制造的结果是否会因一天中的不同时间，或因僵尸的接近程度产生变化。他们用最发散思维的方式去“玩”游戏，往往出乎游戏开发者的意料和构想
12. 设计
#
  • 在设计要素上获得高分的玩家想在身处的游戏世界中积极展现自我。在质量效应这样的游戏中，他们会在捏人过程中投入大量时间精力。而在城市建设或太空策略游戏中，他们则会花时间把他们的城市或飞船设计成自己想要的样子。因此，他们更喜欢那些提供了内容丰富、简单易用的自定义工具的游戏

9种类型
#

1. 杂技玩家
#

杂技玩家是独行玩家，他们主要追求高难度的游戏体验，并会反复练习，直到能够挑战游戏中最难的任务和 Boss。他们喜欢节奏适中、需要思考和自行摸索游戏机制的游戏。杂技玩家不太在意游戏的世界观构建和华丽的装饰。因此，在他们的热门游戏列表中，我们会看到《超级银河战士》、《俄罗斯方块》和《以撒的结合》等作品。

2. 园丁型玩家
#

园丁型玩家追求的是安静、轻松的任务完成体验。他们喜欢规则清晰明了、尽可能直接的游戏，并且游戏过程本身更加自由、灵活。当X事件发生时，我需要做Y。他们不需要提前规划十步，因此不会感到压力或焦虑。园丁型玩家享受完成任务本身带来的乐趣——无论是通关、收集星星/奖杯，还是收集各种收藏品。在他们的热门游戏列表中，我们看到了《糖果传奇》和《动物森友会》等游戏

3. 猎魔人
#

猎魔人渴望成为电影式故事中的英雄主角。他们喜欢拥有强烈创意、精心打造的叙事和体验的游戏。猎魔人是单人玩家，追求节奏较慢、易于上手的游戏玩法。他们不太在意角色成长或战略规划，更喜欢体验游戏当下展开的剧情。从这个意义上讲，猎魔人将游戏视为高度互动的动作电影。因此，在他们喜爱的游戏中，我们看到各种以叙事为主导、流程较为线性且带有轨道式设计的游戏

4. 游击型玩家
#

游击型玩家的动机以行动社交为主——也就是前四项动机的组合。他们追求快节奏的团队竞技游戏，难度不高，不需要太多思考和计划。他们想要的是刺激且易于上手的游戏。较低的完成率意味着他们更倾向于每局游戏结束后所有数据都会重置（而非持续累积）的单局游戏。在他们的热门游戏列表中，我们看到了《使命召唤》和《战地》等在线射击游戏。游击型玩家中女性玩家的比例远低于男性玩家，而且他们的年龄也略低于平均水平

5. 角斗士
#

角斗士玩家更有可能自认为是硬核玩家，他们希望游戏能够通过丰富的功能吸引他们。他们追求史诗般的体验，包括团队竞技场、快节奏的爆炸性游戏玩法、强大的成长机制、需要策略思考的挑战性玩法，以及一个拥有大量探索和自定义内容的丰富世界。在他们的热门游戏列表中，我们看到了许多大型多人在线游戏（MMO）和射击游戏，例如《命运》、《战争机器》和《黑色沙漠》

6. 忍者
#

忍者和杂技演员一样，都热衷于挑战高难度任务。但忍者也追求策略性决策、快节奏的游戏体验和激烈的竞争。因此，他们将电子游戏视为与其他玩家切磋技艺和智慧的场所。较低的完成度得分再次表明他们偏爱每场比赛都从头开始的匹配制游戏玩法，忍者们追求的并非游戏内的进度，而是技艺的精进。在他们的热门游戏列表中，我们看到了《星际争霸》和《街头霸王》等作品

7. 赏金猎人
#

如果说屠戮者追求的是精心设计的线性流程体验，那么赏金猎人则渴望一个能够通过自定义和探索打造属于自己的游戏世界。因此，屠戮者的探索和设计得分较低，而赏金猎人的探索和设计得分则高于平均水平。赏金猎人也热衷于通过角色升级和武器强化来提升实力。他们希望看到自己的角色在游戏世界中不断成长，变得强大。这一点也使他们与屠戮者截然不同，屠戮者似乎并不在意实力提升，而是更注重游戏的每一刻体验。因此，赏金猎人喜爱的游戏包括《黑道圣徒》、《孤岛惊魂》和《质量效应》等

8. 建筑师
#

建筑师玩家渴望在游戏中进行规划和决策，从而推动游戏进程并完成任务。他们也喜欢拥有引人入胜的背景设定和故事情节的游戏。他们强烈偏好单人游戏，不参与团队合作或竞争，以便完全掌控自己的游戏体验。他们偏爱节奏舒缓、轻松宁静的游戏。这类玩家渴望规划并建造宏伟而持久的事物。他们希望随着时间的推移不断完善，并最终使其免遭毁灭。在他们的热门游戏列表中，我们可以看到《欧陆风云》和《文明》系列等作品

9. 吟游诗人
#

吟游诗人是社交型玩家，他们喜欢在充满背景故事、探索乐趣和自定义选项的游戏世界中与其他玩家聊天互动。他们渴望成为宏大故事的一部分，与其他玩家共同创造和塑造游戏世界及其故事。对他们而言，游戏就像一个舞台。他们不太在意角色成长和任务完成，只想自然而然地体验游戏世界。在他们喜爱的游戏中，例如《秘密世界》和《最终幻想14》

行为分层（参与度）
#

根据玩家投入的时间、精力和技能水平，将玩家分为三大类。

  • 休闲玩家 (Casual Gamers)：游戏时间零散，偏好简单、易上手的玩法，留存率较低但用户基数庞大。
  • 中核玩家 (Midcore Gamers)：投入度和技巧介于休闲与硬核之间，寻求比休闲游戏更有深度的体验，但又不像硬核玩家那样投入大量时间。
  • 硬核玩家 (Hardcore Gamers)：将游戏视为重要爱好，投入大量时间，追求高水平的技巧和精通，是社群中的意见领袖。

商业化分层（消费水平）
#

在免费增值（Free-to-Play）模式下，根据玩家的付费金额，通常将其分为三类。

  • 鲸鱼玩家 (Whales)：占比极小（通常为1-5%），但贡献了游戏收入的大部分（40-70%甚至更高）。他们为获得竞争优势、稀有道具或尊贵身份而进行大额消费。
  • 海豚玩家 (Dolphins)：构成付费用户的中间层（约15-25%），他们会进行规律性的、中等额度的消费，以提升游戏体验。
  • 小鱼玩家 (Minnows)：付费金额很小或仅进行过单次小额付费的用户。他们构成了付费用户的底层，个体贡献小但总数多。
  • 免费玩家 (F2P)：构成了玩家基数的绝大部分，从不进行任何付费。
