核心玩法
#

核心玩法循环
#

  • 养成／构筑 —— 验证（战斗、剧情及探索检定）—— 收获／反馈（经验值、装备、剧情影响等）

核心体验
#

  • 玩家通过属性分配、职业选择与装备搭配构筑角色，在回合制战棋战斗、探索检定与对话选择中验证构筑成果，获得角色扮演即如同亲身经历的异世界冒险体验的满足感。

核心玩法的设计思路
#

玩法设计即是为达成体验，搭建与玩家互动的规则。

核心体验拆解
#

  1. 自由地交互；

  2. 受玩家选择影响的冒险故事；

  3. 角色的代入感，世界的真实感。

前两点也是第三点建立的基础。

追问
#

  1. 什么叫自由地交互？

    • 在游戏中自由不是可以做任何事情，而是所有交给玩家的行为，施加在任何符合直觉的对象上，都可以获得应有的反馈。换句话说，游戏规则是值得信任的。

    • 这意味着，玩家可执行的行为是有限的，同时，所有的可交互物体都需要考虑对所有行为的反馈。

  2. 这就衍伸出四个问题：

    1. 玩家有哪些可执行行为？

      • 这与目标体验的第2点相关；

      • 同时还取决于游戏的背景与类型，因为游戏的背景与类型意味着一种承诺，某种体验要素的承诺（会被玩家下意识期待的东西）。

      • 故，需要进一步追问：

        1. 冒险故事有哪些必要的行为？

          • 战斗、探索、交流

            • 什么样的战斗、探索与交流，可由下问统一回答。

        2. 龙与地下城和crpg对玩家的行为做出了什么承诺？

          1. 剑与魔法的回合制策略与环境深度互动的战棋式战斗；

          2. 基于角色属性、技能与装备构筑的战斗与判定；

          3. 基于角色属性、技能检定的探索与交流。

        3. 为什么是回合制？

          • 因为在战斗中，玩家获取到的信息太多（敌人的属性与位置、角色的属性、技能及效果、可能利用的环境与道具等），进行判断决策的时间需求便更多，若为即时操作，对玩家生理（反应与思考）挑战过高负担过重（一般人做不到）。

        4. 为什么需要如此多的信息？

          • 因为游戏的目标体验是，“角色的代入感，世界的真实感。”

          1. 自定义角色是提高代入感的重要手段，而自定义的属性可以对核心系统及故事走向产生影响，便可以使代入感进一步加强（因为玩家所决定的，产生了真实的影响与反馈，而不是背景板）。

            • 这便是构筑玩法在提高代入感方面的作用（装备与技能的选择是玩家个性的体现）。

            • 也因此，角色与敌人的技能装备属性的信息会很多。

          2. 环境包含的信息越丰富，世界越真实；而如果环境的信息可以被利用（比如，敌人旁边有个坑，把敌人推下去可以摔死他），那么环境信息就超越了环境叙事的作用，更加地真实可信。

            • 因此，战斗时玩家需要获取的环境信息也很多。

      • 到此，可以初步得出玩家的可执行行为：

        1. 移动；

        2. 敌对行为（攻击、控制、强制位移等）；

        3. 构筑（装备、技能与属性等的调整）；

        4. 交流（对话、交易、盗窃等）。

    2. 什么叫符合直觉的对象？

      • 对于不同行为，符合直觉的对象是不同的。

      1. 一个关键在于和现实世界的现象是否相近。

        • 例如，移动这一行为，地面当然是符合直觉的对象，而具有足够大小的箱子，也应该可以站在上面。

      2. 另一个要素是普遍性，即如果一个行为对于A有效，那么与A相近的B、C也应当有效。

        • 例如，如果商人可以交易，那么其它NPC也应该可以交易；如果NPC可以被攻击，那么门、箱子等在现实中具备可破坏属性的物体也应该可以被攻击。

      3. 最后是对称性，一些行为往往应该成对出现。

        • 例如，如果甲可以被点燃，那么它也应该可以被打湿；如果可以被拾取，那么就应该可以被放置；可以被偷窃，就应该可以被赠送。

    3. 什么叫应有的反馈？

      1. 符合现实规律。例如，从高处坠落会受到伤害；水能导电、灭火；石头点不燃。

      2. 和上一问相同，即普遍性，即如果一个行为能触发A的某一反馈，那么与A相近的B、C也应当有相似的反馈。例如，buff可以给队友，那么也应该可以给敌人。

    4. 如何在合理有序的前提下，实现物体的丰富反馈？

      1. 鸭子模式（如果一个东西看起来是鸭子，叫声也是鸭子，那么它就是鸭子）。

        • 对于行为而言，应当直接向对象索取需要的数据，而不是对于对象的类型进行判断。

        • 例如，投掷需要对象的重量，那么所有拥有重量的物体都可以被投掷。

      2. 接口模式

        • 若对象自身需要对行为产生变化，那么仅需为这一行为添加对应的接口，并实现接口要求的函数功能。

        • 例如，点燃这一行为。只需为所有物体添加IBurnable接口，并实现各自燃烧状态会产生的反应（掉血、照明等）。用同样的"火焰箭"点燃三种不同物体——点燃"油桶"→爆炸；点燃地面上的"一摊油渍"→仅产生区域持续燃烧；点燃"木制路障"→路障被烧毁变为可通行。相同的输入行为（点燃），不同的输出结果（爆炸/燃烧/摧毁），但共享相同的接口（IBurnable）。

      • 本质上，就是将所有反馈，拆解为一些最基本的数据（血量、抗性、重量等）和状态（燃烧、湿润、投掷中、破坏等）的变化；所有的行为即是对这些基本数据的使用，以及状态的触发。

  3. 玩家如何影响故事走向？

    • 玩家对遭遇的事件的选择会改变之后的内容。

      • 如何改变？

        • 故事由一连串的任务组成；在关键任务触发时设置检查点，根据条件产生不同的结果。

          1. 什么叫关键任务，或者如何设置检查点？

            • 对于支线而言，即在接取任务处判断是否能够触发。

            • 对于主线而言，即在进入下一个区域时，判断如何进入再下一个区域。

          2. 如何选择检查条件？

            1. 前置任务完成情况；

            2. 关键NPC物品的状态；

            3. 角色的属性。

    1. 玩家在多大程度上影响故事走向？

      • 就工作量而言，玩家不会真正影响主线的脉络。实际上玩家改变的是结局，以及进入关键区域的方式。

    2. 如何维持稳定清晰的主线？

      • 正如上一问所说，通过关键区域将故事串联起来。

      • 所有的任务都将玩家推向关键区域（地精营地、月初之塔、博德之门），到达之后，会将之前区域的任务结算并检定。

小结
#

  • 角色的自定义构筑与养成构成了代入感与真实性的地基，事物丰富的反馈，即对角色构筑与属性的针对性验证（战斗、探索、任务），强化了“玩家通过自由地选择与交互，参与并影响的如同真实世界的冒险故事”这一核心体验。

    • 至此，核心玩法循环基本成型：构筑——验证；

    • 而最后的反馈，只是为循环注入了燃料（验证后获得的装备、经验值等可以让玩家升级当下构筑，从而激发再验证的欲望；而可能获得的奖励，也会吸引玩家推进探索，迎接检验）。

  • 而游戏的体验绝不仅取决于核心玩法，接下来将分析游戏系统框架是如何与核心玩法结合，从而强化辅助核心玩法循环的各个部分，进而强化目标体验。

核心玩法与游戏系统框架如何结合
#

探索系统
#

核心机制：

  1. 察觉检定：基于感知属性。自动触发，用于发现隐藏的陷阱、暗门、宝箱与埋伏。察觉检定失败时，玩家可能踏入陷阱或错过秘密区域。

  2. 环境交互：推/拉物体（基于力量属性）、投掷物品（基于力量属性）、跳跃（基于力量/敏捷）、攀爬。所有交互均遵循前述"鸭子模式"——任何有重量属性的物体都可被投掷，任何可推动的物体都遵循物理规则。

  3. 物品交互：钥匙开门、撬锁（基于敏捷+巧手熟练）、点火/灭火、泼洒液体（油、水、毒）等。

与核心玩法的结合方式：

  • 探索系统本质上是构筑的验证场景。玩家的属性分配直接影响探索能力：

    • 高力量角色可以推开重物开启捷径，投掷敌人/物体制造战术优势；

    • 高敏捷角色可以撬开锁住的箱子、潜行通过危险区域；

    • 高感知角色能发现隐藏的道路与宝藏；

    • 高智力角色可通过历史/奥术检定解读古代文字，获取隐藏信息。

  • 这种设计使得探索不是与战斗割裂的独立系统，而是构筑的另一个验证途径。

社交系统
#

核心机制
#

  1. 对话检定：

    • 说服：基于魅力属性，以理服人，让NPC接受玩家的提议。

    • 欺瞒：基于魅力属性+欺瞒熟练，通过谎言达成目的。

    • 威吓：基于力量或魅力属性，以武力或气势胁迫NPC。

    • 游说：基于魅力属性，以才艺打动NPC。

    • 检定结果直接改变NPC的反应与后续剧情分支。

  2. 同伴好感度系统：

    • 每个同伴有自己的价值观与偏好，玩家的行为和对话选择会影响好感度。

    • 好感度达到阈值可推进同伴个人任务线。

    • 好感度过低可能导致同伴离队甚至反目。

    • 好感度也影响结局（不同同伴在不同好感度下会有不同的结局走向）。

  3. 阵营与道德：玩家的选择影响世界中NPC对玩家的态度。例如，帮助地精营地与帮助德鲁伊营地是互斥的，选择一方会改变另一方对玩家的态度及后续可用内容。

与核心玩法的结合方式
#

  • 社交系统使魅力型构筑有了独立于战斗的价值。：

    • 说服NPC跳过战斗；

    • 获取额外信息与隐藏任务；

    • 以更低代价达成目标（如说服商人降价、说服守卫放行）。

  • 同时玩家自身的对话行为选择也是角色构筑的一环，也就是说玩家的意志也会被游戏反馈验证，融入“构筑——验证"循环，这正是核心玩法循环在社交维度的延伸。

战斗系统
#

核心机制
#

  1. 动作资源：每轮角色拥有一个标准动作、一个附赠动作、一个自由动作和一个反应，这些资源分配是回合制战术的核心决策。是先移动占据高地（自由动作）、施放远程法术（标准动作）、 喝药水（附赠动作）；还是冒险冲到敌人面前进行连击，每个回合都是资源分配的一次最优解计算。

  2. 地形与高度：高地攻击获得命中加值（高地优势）；站在悬崖边缘可被推下造成坠落伤害；复杂地形（云雾、蛛网、油脂）影响移动速度与视线。这些因素使位置本身成为一种战术资源。

  3. 环境战斗：爆炸物（油桶、火药桶）可被远程攻击或火焰触发；水体可被通电形成持续伤害区；火焰可点燃油脂形成燃烧区。环境不仅是背景，而是"可激活的战术资产"。

  4. 遭遇设计：非对称遭遇是该游戏战斗设计的原则，敌人数量、质量、地形优势往往不对等，迫使玩家利用一切可用资源而非单纯拼属性。

    • 例如，第一章地精营地门外，大量地精和座狼占据高地且有掩体。
与核心玩法的结合方式
#

战斗系统作为构筑验证的核心场景，角色的每一项属性、技能、装备都在战斗中产生直接的数值和策略影响。举第一章地精营地门外遭遇为例，不同build的解法完全不同：

  • 力量型战士：利用力量跳跃到高台旁，推退动作将敌方远程单位推下悬崖（力量检定 vs 敌人力量豁免），占据高地利用高地优势近战清理剩余敌人。

  • 敏捷型游荡者：战斗开始前潜行至掩体后方（隐匿检定 vs 敌人察觉），偷袭先手击杀敌方弓箭手（偷袭伤害依赖敏捷+熟练），解除最大威胁后逐个处理近战敌人。

  • 智力型法师：利用睡眠术（智力法术 vs 敌人感知豁免）控制食人魔，火焰箭引爆油桶（远程攻击检定）对聚集的敌人造成范围伤害，保持在高处利用高地优势持续输出。

  • 魅力型术士：利用威吓对话选项在战斗前降低敌人警戒度（魅力检定），获得先手优势。

同一场战斗，每一种build都有一套独特且有效的解法，以获得不同的体验。这正是“构筑——验证”循环在战斗维度的体现。

亮点
#

  • 游戏的所有系统（战斗、探索、社交、环境交互、物品交易）使用同一套角色数据。

目的
#

  1. **统一认知，降低学习负担：**玩家不需要单独理解战斗系统、探索系统、社交系统的规则。力量高，所以能推开巨石、能把敌人扔下悬崖、能用拳头吓唬NPC。魅力高，所以法术更强、能说服NPC、能拿到更便宜的价格。玩家不需要在不同的系统之间切换思维模式，角色属性本身就是所有系统的统一接口。

  2. **更强的真实感：**真实感的来源不是画面或物理引擎，而是游戏世界对玩家的回应始终保持一致。无论在战斗中、探索中还是对话中，游戏用统一的方式回应玩家（属性值）。

设计思路
#

  • 接下来，通过3个系统实例来看看这种统一底层数据的设计思路。

环境交互
#

  • 环境物体与角色共享同一套底层数据结构（血量、重量、抗性、状态）。

    • 推开一只地精和推开一个木箱，进行的是同一个力量检定——系统不区分"角色"和"物体"，只读取重量属性。

    • 点燃一张蜘蛛网和点燃一件木质家具，走的是同一个IBurnable接口。

  • 这意味着玩家的构筑决策直接决定了可利用的环境范围：

    • 高力量角色推开巨石开启捷径、投掷油桶制造爆炸（力量同时是战斗属性和探索属性）；

    • 高感知角色发现陷阱、密道和机关。

叙事
#

  • 对话检定使用与战斗完全相同的属性系统，而非独立的对话技能点。

    • \[威吓\]

      选项可以由力量属性支撑；

    • \[历史\]

      检定依赖智力；

    • \[察觉\]

      检定依赖感知。

  • 这意味着不同构筑体验到的故事不同，不仅是难度的不同，还是路径的不同：

    • 高魅力角色可以说服Boss直接跳过战斗；

    • 高力量角色可以威吓守卫放行，以蛮力打开对话中无法通过的其他路径；

    • 低智力角色根本看不到需要知识检定的对话选项。

  • 同伴好感度同样与构筑选择产生化学反应。

    • 例如，高魅力角色拥有选择专门的对话选项，这会让影心赞同，但会让莱埃泽尔不赞同。玩家的属性倾向无形中影响了与不同同伴产生共鸣的可能。

法术
#

  • 法术不按"战斗/探索/社交"分类，而是改变玩家与世界互动的某条规则，这条规则在所有场景中统一生效。

    • 羽落术：将"高处坠落"从风险变为工具。战斗中可从高地安全跃下突袭，探索中可抵达原本会摔伤的低处区域。

    • 敲击术：用法术位替代撬锁检定。智力型角色获得了一条不依赖敏捷的开锁路径。

    • 神导术：增益所有属性检定。它不产生任何伤害或剧情分支，却以极小的幅度渗透进几乎每一次检定。

    • 迷踪步：将位置从移动可达变为视线可达。战斗中可传送至高地获得战术优势，探索中可穿越铁栏获取原本无法触及的宝箱。

  • 法术位作为跨场景的共享资源池，使每道法术的跨场景价值在资源层面形成竞争。

    • 在战斗中消耗一个2环法术位用迷踪步逃生，意味着探索中少了一次穿栏取宝的机会。

    • 战斗不再是唯一的检验路径，战斗作为一般RPG的核心地位，让位给了《博德之门3》的核心体验（角色扮演）。

属性值的数值设计
#

有限分配
#

  • 初始属性点数和升级属性提升机会都是有限的，这意味着每在一项属性上投入一点，就在其他所有属性上少了一点。

目的
#

  1. **策略性：**拒绝均衡分配的六边形战士，迫使玩家选择取舍，形成独特的构筑。

  2. **代入感：**而独特构筑在游戏中，带来不同的体验（靠高魅力说服，还是高力量威胁，或直接战斗），进而强化角色对于玩家的特殊性（即使玩家意志的体现）。

不同职业依赖不同属性
#

  • 不同职业的战斗力，所依赖的属性是不同的（如，战士需要力量、术士需要魅力、法师需要智力等）。

目的
#

  1. **强化构筑的重要性：**如果每项属性对所有职业都有相同的重要性，那么构筑就没有方向可言（如上一条的目的1）。这种设计确保了，选择一种构筑方向，必然意味着放弃其他方向的可能性（不仅是战斗能力的放弃，还包括探索和社交能力的放弃）。

  2. **代入感：**也正是因为角色的构筑自然地带来限制，其属性上的倾向也带来战斗、探索等方面的其他优势。这样的局限与优势，在游戏中不断地验证，形成角色独特个性的代入感。

与《神界原罪2》比较
#

关键差异
#

  1. 数据架构：《博德之门3》的六项属性在战斗、探索、社交中统一读取；《神界原罪2》将民事能力（交易、鉴定、潜行、撬锁等）与战斗能力分属不同的点数池，二者互不影响，不同系统相互独立。

  2. 战斗系统：《神界原罪2》采用双护甲制（物理护甲+魔法护甲），敌人需先破对应类型护甲才能施加控制效果；《博德之门3》采用AC+豁免检定。

  3. 演出：《博德之门3》的每个对话都有细腻的动画演出和配音，《神界原罪2》仅有配音。

优势
#

  1. **统一数据带来的认知降低与沉浸强化：**玩家只需理解一套属性系统，即可在所有场景中预测自己能做什么、不能做什么。这种一致性使世界可信的体验贯穿全程，而非仅在战斗或探索中成立。

  2. **更低的上手门槛：**统一数据带来的一致性与认知降低，让复杂系统更易理解，配合电影级过场叙事，使更多玩家能够接受。

劣势
#

  1. **AC+豁免检定失败的挫败感极强：**游戏前期，因为属性值较低，玩家攻击很容易被豁免（即闪避掉），无法造成伤害。
