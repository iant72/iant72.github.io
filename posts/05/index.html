本文通过分析深境螺旋的设计目的与在当下游戏中的定位，找出需要优化的部分，进而提出迭代方向与思路。

深境螺旋的设计目的
#

  1. 深渊的主要目的是通过具有一定难度的战斗，验证玩家的养成成果与战斗理解；换句话说，为玩家展示其养成成果与战斗理解提供舞台。

  2. 深渊因其带有珍贵奖励，在失败时作为负反馈，引导玩家提升战斗力【战斗力具体可分为：角色（等级、命座、技能等级）、武器（等级、叠卡）、圣遗物、操作、理解（对角色以及敌人机制的理解）】、推进养成进度。

    1. 战斗理解本质是一种学习，而当玩家可以通过学习达成某个成果时（打败敌人、大额伤害等），学习本身也就会产生乐趣。

    2. 另一方面，当玩家越发理解战斗机制时，他可以根据自己的理解，通过排轴打出高效伤害、通过元素反应瓦解敌人机制，从而使战斗中精准操作（小脑的满足）、对策化解（智力满足）、伤害特效（视听激励）带来的乐趣加强。

  3. 通过调整每期的敌人特性、词单效果使当期up角色能够更容易地通关，从而增强玩家的抽取意愿（进而增加充值的可能性），并且也是对已抽取的玩家的抽取行为给予肯定积极的反馈（巩固以后抽取当期角色的意愿）。

  • 接下来，将根据不同玩家、不同游戏阶段讨论深渊的作用。

1-8层
#

  • 敌人种类固定，等级从25随层数涨至70级，奖励是一次性的，故主要是针对于游戏前期即新手玩家。

其作用在于：

  1. 通过珍贵奖励与较强的敌人，引导玩家推进养成进度（这也是奖励一次性的原因，当玩家的养成进度达到通关要求后，之前的关卡的难度便不足以让玩家推进养成，也就不必要求玩家反复通关。），并对玩家已达成的养成成果予以体现和奖励。

  2. 通过比野怪更难的敌人，加深战斗机制（基本的元素反应等）的理解。

  • 主要验证战斗力中的：角色及技能等级、武器等级、基本操作，以及基本的战斗理解。

9-10层
#

  • 每月更换敌人种类，并刷新奖励，敌人等级从72到85级逐层递增。在上期满星通关第11层可跳过9层，满星通关第12层可跳过10层。主要对于游戏中期即新手向老玩家过渡的阶段，以及对于强度和战斗不感兴趣的玩家。

    • 其作用与1-8层基本相同，只是针对的玩家及游戏阶段不同。

  • 因此导致的主要差异来自以下几个问题：

    1. 为什么可以跳过：当玩家的养成进度达到满星通关第11、12层要求后，9、10层的难度便不足以让玩家推进养成，也就不必要求玩家反复通关。

    2. 为什么不像1-8层变为一次性内容：

      1. 将角色从9层养成至11层的强度水平，所需要的时间要大于深渊更新的周期，需要这部分的原石来使抽卡充值的意愿提高（接近大保底）。

      2. 对强度和战斗不感兴趣的玩家，对于刷取足够强力的圣遗物的意愿不高，9-10层便作为这类玩家深渊的终点，周期性地获取原石资源（同上）。

        • 同时，当玩家达到这一强度后，便不至于在探索、主线、材料刷取等非战斗作为核心体验的部分，因战斗困难而导致体验受阻（进而有更多的设计空间，以提供更丰富的内容）。

11-12层
#

  • 每月更换敌人种类，并刷新奖励，敌人等级从88到100级逐层递增。主要对于游戏中后期即已入门的玩家。

    • 其作用与1-8层基本相同，只是针对的玩家及游戏阶段不同。

  • 因此导致的主要差异有：

    1. 主要验证的战斗力变为：角色适配及命座、武器适配、圣遗物适配与强度、更精准的操作，以及配队、排轴等进阶战斗理解。

      1. 其中角色适配及命座、武器适配，与商业化高度相关，是用于提高玩家抽取当期角色与专武的意愿。

      2. 圣遗物的适配与强度，将玩家导向可供大量消耗的刷取内容中，以维持玩家的活跃度。

小结
#

  1. 验证养成成果与战斗理解。

  2. 引导新手掌握基本战斗机制与技巧。

  3. 引导玩家推进养成进度，消耗养成资源刷取内容。

  4. 提高玩家抽取当期角色与专武的意愿。

深境螺旋的现状与定位变化
#

随游戏内容与玩家的成长，深渊渐渐难以达成目的。同时游戏也对此做出了一些改变，但这也导致了深渊自身的定位发生了变化。接下来便要讨论深渊当下的定位与不足。

高不成
#

对于拥有高命座或高战斗理解与操作的玩家而言，深渊最高的难度已经起不到验证的作用。而增加难度无疑会引起非强度战斗偏好玩家的不满。

  • 幽境危战满足了这一需求。其4-6难度没有原石奖励（而是偏向情绪价值的武器皮肤），避免了对非强度战斗偏好玩家的捆绑，也使其免于利益驱动（而是通过验证自身战斗力的内驱力驱动）。

  • 故一部分高难验证作用被让渡。

膨胀还是不膨胀
#

角色的强度成长是收敛的（即存在一个上限），当玩家已拥有接近强度峰值的角色时，如何让他用动力养成新的角色，甚至抽取新角色变成了一个问题。

机制与数值的差异化便是必要的解决途径。

  • 而机制并不直观，甚至需要学习（人是懒惰的）。

  • 而数值的膨胀，会让玩家在抽取时产生角色很快会被淘汰的焦虑与不满（导致抽取意愿下降）。

幻想真境剧诗提供了学习熟悉角色机制的途径，同时对角色数量的要求使得大量角色有了出场的机会。

  • 故一部分进阶机制的学习，以及养成的引导的作用被让渡。

    • 但是，幻想真境剧诗与传统的战斗（一到两队）差异较大，存在入门阵痛。

草、夜魂与月
#

1-8层没有安排草属性、夜魂机制以及月反应的战斗验证，对于当下的新人而言是有所缺失的。

外驱力与策略退化
#

不可否认战斗是原神乐趣的重要来源，而战斗的同时获得原石，使得深渊同时存在战斗乐趣驱动（内驱力）和原石利益驱动（外驱力）。而人往往会倾向于将行为归因于更明显的外驱力，故而使得深渊在体验上成为了劳动场所。

  • 此时，为了让当期角色更有吸引力的buff与敌人，会使得玩家更倾向于选择他而不愿意再了解其它战斗机制。

小结
#

  1. 高难验证作用被让渡给幽境危战。

  2. 部分进阶机制的学习，以及养成的引导的作用被让渡到幻想真境剧诗。

  3. 草属性、夜魂机制以及月反应的战斗验证缺失。

  4. 外驱力使得机制学习的作用受影响。

迭代方向
#

结合上述的深渊的设计目的，以及当下的种种不足与定位变化，深渊的迭代方向也渐渐清晰。

  1. 作为玩家过渡到幻想真境剧诗与幽境危战的战斗养成的准备。

    1. 因此，需要为玩家了解不同角色的机制提供环境；

    2. 将高难部分舍弃。

  2. 补足1-8层草属性、夜魂机制以及月反应的战斗验证。

  3. 为愿意游玩幻想真境剧诗与幽境危战的玩家腾出时间与精力。

  4. 维持对当期角色与专武的吸引力。

  5. 补足游玩深渊的内驱力。

迭代思路
#

  1. 在1-8层中，将部分敌人替换为须弥及之后版本的新敌人（草系敌人、纳塔夜魂系敌人），使新玩家在前期即可接触并理解草元素反应、夜魂机制与月反应。

  2. 降低9-12层的敌人难度，12-3的敌人难度小于等于幽境危战n3。

  3. 增加特殊的第13层，其具体内容如下：

    1. 敌人难度在幽境危战n3与n4之间；

    2. 无原石奖励；

    3. 通关后下一期深渊可跳过11、12层；

    4. 改变原来的祝福机制为天平机制（类似《神之天枰》）：

      1. 从新一期深渊开始起，每一周增加数个增益与减益词条（最开始的词条以及之后的部分词条，需要对当期角色有足够的倾斜）；

      2. 根据效果强弱，每个词条拥有1-3不同的权重值；

      3. 玩家选取的减益与增益词条的权重值必须相等才可以开始作战；

      4. 结算界面展示参战角色，各角色造成的伤害，所选词条，以及天平的权重值。

解释
#

迭代思路1
#

  • 显而易见，补全新机制验证。

迭代思路2
#

  • 将深渊最高难度锚定于幽境危战n3，确保深渊作为大众验证舞台而非高难挑战的定位（高难验证已由幽境危战n4承担）。同时，降低后的9-12层仍保留养成验证价值（配队合理性、元素反应理解、基本操作仍然是通关前提，只是不再要求极限练度）。

迭代思路3
#

  1. **保持深渊接受度的稳定：**不对1-12层的机制做修改，避免玩家对陌生的变化的天然排斥；同时不设原石奖励，为反复挑战的内驱力排除隐患，同时避免影响版本中原石资源的安排。

  2. 挑战的初始动机：通关可跳过11、12层，让玩家有尝试挑战的初步动力。同时，减少在深渊所消耗的时间（之前是2层，现在是1层）。

  3. 商业化与乐趣的平衡：词条对于当期角色的倾斜，让拥有当期角色的玩家可以更快更容易地通关，以强化玩家的抽取意愿，并且也是对已抽取的玩家的抽取行为给予肯定积极的反馈。

    • 同时，更丰富的词条允许没有抽取当期角色的玩家搭配出较容易通关的队伍（尽管会晚几周等词条），进而引导玩家研究不同角色的机制。

  4. 机制隐形教学：增益与减益两类词条，可以辅助玩家理解角色机制，让玩家在筛选减益词条时自己发现某个减益对角色影响很小，让玩家觉得自己很聪明（类似于《土豆兄弟》，某强化增加子弹威力但降低近战攻速，那么玩枪械流角色的玩家就可以零成本增强；以帮助玩家发现角色真正依赖的机制与属性）。

  5. 社交传播：结算界面便于玩家间分享传播，间接激励玩家挑战不同的配队与更高的权重值（类似危机合约）。

  6. 作为过渡到幻想真境剧诗的桥梁：天平机制在“推销”当期角色的同时，又起到引导玩家研究不同角色机制（进而养成更多角色）的作用，以此为幻想真境剧诗奠定角色理解与养成基础，使过渡更丝滑。

  • 与祝福机制的对比：

    • 玩家可以自主选择增益与减益，在不自觉间加深对角色机制的认识，同时减弱强行推销的感觉。

    • 更高的可重玩性（词条与配队组合更多样）。

例子
#

  • 当期角色：宵宫

    • 宵宫的核心机制：弓箭；普攻输出；战技核心；火元素伤害

词条（第一周）
#

增益词条
#

弓强化：弓箭角色普攻伤害+40%；权重：3

火强化：火元素反应伤害+25%；权重：2

攻速强化：普攻攻速+10%；权重：1

战技强化：战技持续时间+10%；权重：1

减益词条
#

大招弱化：元素爆发伤害-40%；权重：3

充能弱化：充能效率-20%；权重：2

防御弱化：防御力-10%；权重：1

雷弱化：雷元素反应伤害-10%；权重：1

之后可能的词条
#

例如，融化伤害+30%、激化伤害+30%、角色无法闪避、石化期间对敌人每秒造成最大生命值4%的伤害等

设计目的
#

让拥有当期角色的玩家感到物有所值，而没有的玩家可以在研究替代方案的过程中理解不同角色的机制差异（为幻想真境剧诗奠定角色理解与养成基础）。
