本文作为《自动化系统大一统理论与应用》的补充，未直接使用“自动化大一统理论”，但基本思路仍是一致的，只为避免未读过的读者对“自动化大一统理论”相关概念感到困惑。

单一速度的传送带
#

简述
#

  • 以固定的速率将物品从一个设施传入另一个设施。每秒0.5个物品。平面且不可交叉。

  • 同时设施每秒消耗的物品均为0.5的倍数。

  • 存在分流器与汇流器，可将物品的传送速度减半，或相加（上限仍为每秒0.5个物品）。

体验与比较
#

当玩家连传送带时，玩家究竟在思考什么
#

  • 逻辑规划：

    • 根据消耗次级资源的种类与速度，判断需要连几个传送带过来。例如，每秒需要3份A，假设生产A的设备甲的产速为1，那么需要从三台甲每台连两个传送带，到本设备。如果设备甲的产速为2，那需要两台甲，一台连4个，一台连2个（另外两个可能连到仓库，也可能连到另外的设备。）。

    • 根据生产的产物的种类与速度，判断需要连几个传送带出去。例如，每秒生产1份B和1份C，那么需要连4个传送带出去。

    • 无论是来是去，如果消耗的速度为0.25，那么，对于需要对满载的传送带分流为两个，只将其一连入（另一个，视情况连入仓库或其他设备）。

    • 事实上，连传送带与逻辑规划无关，因为在连之前，玩家已经且必须根据自己需要的最终产物的种类与数量，决定了所有中间设备所需要的传送带的数量与来源去处。但是，本文其它部分，对于这一决策不会提及，故写于此。

  • 空间规划：

    • 在连传送带时，为确保每个都正确连到玩家安排的位置。玩家需要不让传送带挡住其他设备或传送带的位置，且不要堵住需要使用的出入口，且保证在可建设的范围之内。

传送带的其它作用
#

【成就】

  • 将玩家的生产成果及过程，通过传送带不断运送物品的形式，可视化地展现出来，让玩家可以看到，获得成就感。

引入高级传送带会发生什么
#

  • 偷懒是人的天性，即使这个行为会破坏游戏的乐趣（如开挂）。当然高级传送带不是洪水猛兽，但是，引入之后玩家必然在所有需要使用传送带的时候使用高级传送带。因为，当只一个传送带时，若产速为1，那么0.5速度的传送带会使设备堵塞，而1速或更快的传送带则不会（向下兼容），所以，只要都用高级传送带，则会使堵塞的问题减到最少且不会引入新问题。

  • 故，引入高级传送带意味着，游戏中所有的传送带都将变为高级传送带。

  • 此时，在某些情况下（例如，甲设备每秒消耗1份A，而乙设备每秒生产0.5份A。引入前，需要两个乙连两个传送带到甲，而引入后，可将这两个传送带通过汇流器变为一个再连入甲。），可以减少空间的消耗，从而使空间规划更加容易（可使用空间变多了）。

    • 也就是说，高级传送带增加了汇流器的使用机会，玩家通过思考找到上一段所说的相似情况，从而减少空间的使用。

  • 综上，若单独引入高级传送带，在堵塞可能性下降的同时，玩家可以通过消耗脑力来减轻空间规划的难度。

设计目的
#

  1. 【维持空间规划的难度】若单纯引入高级传送带，如前所述，空间复杂度会下降，导致策略难度偏离目标（对于其它有高级传送带的游戏如《戴森球》，高级传送带的引入，是为了对之后出现的、更长更复杂的产线带来的难度上升预留难度空间，使策略难度稳定。并且作为可以偷懒的工具，驱动玩家推进游戏，获得它）。

  2. 【降低泛二次玩家上手门槛】多样的传送带增加了玩家记忆与理解的负担。玩家对于陌生的玩法系统，比起执行（空间规划）难度，记忆新信息是更劝退的。

自动销毁的总仓库
#

简述
#

  • 通过传送带接收物品。总仓库容量无限，但每个品类存在存储上限。若总仓库中该品类存在达上限，则传入的物品自动销毁。

  • 远程仓库，通过传送带接收物品，并将物品以一定速率传送至总仓库；

    • 若总仓库中该品类存在达上限，终止传送，并造成堵塞，进而使相应的产线停止，即爆仓。

体验与比较
#

仓库的使用场景
#

  1. 理论上，一个消耗与产出配平的产线是不需要仓库的。而实际上，有两种情况使仓库成为了必需的一环。

    1. 产能溢出，当对某个产品的需求，不是其最小单位产速的整数倍时，为避免堵塞产线（爆仓的产物所在的产线，可能不止服务于这一个产品。所以，即使爆仓的产品可以停产，但被牵连的产线是无辜的。），就需要将其放入仓库储存（或者倒入垃圾桶）。

    2. 平均消耗速率与产速持平，但每次消耗的时间间隔大于生产（例如，每五秒消耗一次，一次消耗100个A，而A的产速是每秒20个。故，需要在每次消耗之前将这100个A先储存起来）。

  2. 在《终末地》以外的工厂游戏中（如《戴森球》），当某产线的消耗小于产出时，仓库的该产品会逐渐积累至上限，最后阻塞产线。此时，爆仓作为负反馈，让玩家返回去研究产线的消耗配比，或新建仓库（因为消耗它的其它产线还未搭好，需暂时储存），或新建修改产线将其消耗，让产线越发高效，同时让玩家对游戏的理解加深。

为什么引入自动销毁功能
#

  • 《终末地》的总仓库是将仓库与垃圾桶集成在一起的产物。

    • 换句话说，当某个产品的产能溢出时，总仓库会自动销毁多余的部分。较之《戴森球》，免去了计算某产品多了多少，并规划一条传送带将其连入垃圾桶，且不会挡住其它产线的放置。

  • 虽然仓库的负反馈效果消失了，产业报表（可以看到个资源的消耗与产出）却弥补了这一需求。

  • 所以，自动销毁的总仓库降低了空间与逻辑规划的难度，让泛二次元玩家更容易上手，不被劝退。

为什么远程仓库不引入自动销毁功能是糟糕的设计
#

远程仓库的使用场景
#

  1. 当仓库的入口不足时（包括被挡住），建立远程仓库可补充入口。

  2. 当将传送带连入仓库，会干扰其他产线（占用太多面积，将大块的面积切碎，挡住其他产线），可以使用远程仓库来避免。

  • 总之，是对空间规划复杂度的降低。
推测其除上述以外的目的
#

  1. 和其他游戏的仓库一样，将爆仓作为负反馈，让玩家返回去研究产线的消耗配比，或新建仓库（因为消耗它的其它产线还未搭好，需暂时储存），或新建修改产线将其消耗，让产线越发高效，同时让玩家对游戏的理解加深。

    • 如上文所述，这一功能已经由产业报表实现了。所以远程仓库的负反馈成了负面反馈。

  2. 为了让玩家在使用远程仓库时产生取舍，即冒着可能堵塞产线的风险来降低空间规划的难度，还是进行更复杂的空间规划连入总仓库避免堵塞产线的风险。

    • 然而事实上，配平作为工厂游戏的核心乐趣，玩家在搭建产线时，一般会使用配平或他们认为配平的产线。故，堵塞产线的风险是虚假的风险，玩家不是在赌产线不会堵塞。

    • 这一策略取舍和玩法的核心相冲突，是不合时宜的。

  3. 提供一种进阶思路：当产能溢出，对某个产品的需求，不是其最小单位产速的整数倍时，若将其连入远程仓库，可以在爆仓后，使其实际产速降低至消耗速度，从而节省相关的次级资源，用作他用。

    • 然而这一进阶思路，是提供给硬核玩家的乐趣，对《终末地》的大多数泛二次元玩家来说是无用的。
  • 综上，对于其带来的上述负面反馈得不偿失（纯亏）。
更好的远程仓库
#
  • 添加自动销毁开关（默认开启）。触发时显示警告，直到下一次传送不触发自动销毁时解除。并且警告可以手动关闭，再次开启时的默认状态为无警告。

电力
#

简述
#

  • 每一个大区域共享一个电量系统，电量储备存在上限，除发电设备外的设备均会消耗电量。

  • 当消耗大于生产，会消耗电量储备，反之恢复。电量储备为零，且消耗大于生产时，设备停止工作。

  • 发电设施会占用一定面积，消耗一定资源，并产生电量。

最小设计，最大难度
#

  • 电力的体验相当明显，就是让空间与逻辑规划变复杂。

    • 逻辑规划上，在计算配平时，要考虑消耗的电量，从而判断是否需要新建发电产线。

    • 空间规划上，供电设备需要放置在其他设备的一定范围内，且不可挡住其他产线和传送带；而发电设备及其产线，也需要想其他产线一样规划（详见传送带）。

  • 而它与增加中间产物的种类的不同在于：一般而言，每一个加工设备若要增加中间产物的种类，就需要新增一个新的中间产物；而加入电力这样的资源，等于在每一个加工设备增加电力作为中间产物。

    • 这意味着，玩家只需要记忆最少的新资源，就可以获得最大的空间与逻辑规划复杂度提升。

    • 正如之前所说，玩家对于陌生的玩法系统，比起执行难度，记忆新信息是更劝退的。故，电力这样的资源加入，可以以最小的记忆负担，将空间与逻辑规划复杂度提升到（对泛二次元玩家而言）需要的程度。

天有洪炉
#

简述
#

  • 上限为12个（随完成任务解锁），生产速率固定，也就是说产量上限固定。

工厂游戏的短期驱动力
#

  • 资源——生产——资源，是所谓的面多加水水多加面的系统循环，采集资源进行生产，扩大生产就需要更多的资源，去采集更多资源，就可以更加扩大生产从而有需要更多资源……

  • 而这扩大生产所需的资源，或者说提高资源产量的欲望，就是工厂游戏的短期驱动力。

《终末地》的应对
#

  • 对于传统的买断工厂游戏而言，这样的短期驱动力会一直持续至游戏的后期，《异星工场》对星球的不断探索，《戴森球》的一个个星球，都有大量的基础资源的增长空间。

  1. 《终末地》的第一个困境就是，每个版本用于矿点的空间有限。当然，这还比较好解决，《终末地》也是这样做的，即矿点数不变，随进度改变单个矿点的产量。

  2. 第二个难点是，建设面积有限。基础矿物产量增加，那么消耗它们就需要建更多产线，进而需要更多的建设面积。对此，也不是无计可施，使用单独的场景做一个大的建设空间（不考虑跳转场景带来的其他影响）。（《终末地》选择停止增加产量，只能接进入平台期。）

  3. 第三个，也是最严峻的。《终末地》是复合了JRPG的二游，玩家的时间并非全部，甚至只有一小部分投入到工厂系统。

    • 对此《终末地》选择分版本渐渐引入新矿点，以补充游戏内容，而天有烘炉这随进度解锁且有上限的特性，也是作此用处。

为什么不是新矿点
#

  • 天有烘炉对于矿点的不同也很明显：

    1. 占据一定的面积。

    2. 生产出息壤需要消耗次级资源。并要搭建相关产线。

  • 故，其作用也很明显，引入新产线的同时增加难度。

    • 为什么要增加难度呢？

    • 因为，玩家对于游戏的理解提升了，若难度不变，其实就是变简单了，而对于设计好的难度而言，变难和变简单都是在降低乐趣。

分布式面积
#

面积分散
#

  • 乍一看，可建设面积分散似乎在限制长产线以降低空间复杂度。而事实上，产线是模块化的。工厂游戏的一个技巧就在于，将中间产物的产线视作一个个模块，这一个个模块根据比例拼接，从而实现复杂的流水线的搭建。

  • 所以，将可建设面积拆分，便是暗中要求玩家进行这种模块化的搭建。换句话说，当一个地方放不下一个复杂的产线时，玩家自然地就会将其拆分为中间产物组成的模块，放在不同的区域中。

总仓库与限制进出货口
#

  • 将面积限制与进出货口限制结合起来便能发现其中的秘密。

  • 先看《异形工厂》。

  • 总仓库的存在即是对出入口数以及位置做限制，从而限制产线的起点与终点，以提高空间复杂度。

    • 而此时再将面积加以限制，高空间复杂度也会进一步提升。

    • 那么为什么要如此专门地提高空间复杂度呢？

      • 比起抽象的计算，可视化的规划更容易让人接受，即同等情况的复杂度，比起逻辑复杂度，空间复杂度更容易让人接受。尤其是目标用户是中轻度的泛二次元游戏的《终末地》。

  • 所以，无论是出入口数限制，还是面积限制，都是在控制产线的长度与各级资源的种类，以减少逻辑复杂度的同时，保证空间复杂度，以维持乐趣（对于中轻度玩家）的空间复杂度优先的设计思路。
