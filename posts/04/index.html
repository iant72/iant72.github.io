IP设定
#

盛露厅在奥藏山遗迹发现特殊磁珠，一些样品被放于群玉阁研究。不料一次雷雨，天雷似乎被磁珠吸引，击中了群玉阁中的样品与正往璃月港运输途中的磁珠。电场导致磁珠失控四散无踪，璃月七星希望旅行者帮助寻回磁珠。

核心机制
#

  • 参考游戏：《Öoo》（炸弹毛毛虫）

参考游戏机制概述
#

  1. 可在正下方生成炸弹；

  2. 在空中与位移时不可生成炸弹；

  3. 最多同时存在2个炸弹；

  4. 只能先引爆最先放的炸弹；

  5. 引爆炸弹可以将与之相邻的玩家和炸弹沿直线推动一段距离，然后恢复重力影响；

  6. 玩家与被推动的炸弹相邻时，相对位置不变；未引爆炸弹与被推动的玩家相邻时，相对位置也不变；

  7. 炸弹与其它场景元素的互动不会引入到活动，在此不赘述。

游戏活动机制概述
#

为符合磁力主题的微调
#

1. 磁极系统

  • 磁极类型：正极（红）/ 负极（蓝），二选一。

  • 磁极可变更时机（仅以下两个时机，其余时刻磁极锁定）：

    1. 生成前：摆放状态预览时，通过滚轮切换预放置磁盒的磁极；

    2. 激发瞬间：激发时可反转该磁盒的磁极。

  • 边界限制：已放置且未激发的磁盒，磁极不可变更。

  • 边界限制：磁珠的磁极在生成时固定，全程不可变更。

2. 磁盒拼接

  • 触发条件：放置时相近则自动吸附拼接。

  • 拼接方向：支持 6 个正交方向，不支持斜向拼接。

  • 边界限制：同性磁盒即使相邻也不拼接，无任何特殊效果。

  • 边界限制：已拼接的磁盒组姿态固定，不受重力/碰撞影响而倾倒。

  • 边界限制：拼接后只能通过激发（相斥分离）解除，不可手动拆分。

  • 失败处理：拼接判定时若一方磁盒正在被推动（运动中），待其停止后再判定，避免穿模。

3. 磁盒激发

  • 触发条件：玩家站立或攀爬在最后放置的磁盒上；

  • 激发顺序：仅能激发最先放置的磁盒，单次激发 1 个。

  • 激发效果：

    • 相接磁盒组中所有磁盒磁极统一为激发时指定的磁极；

    • 同性相斥，磁盒组沿拼接接触面法线方向互相推动分离。

  • 边界限制：玩家未站在最后放置的磁盒上时，激发操作无效（可给 UI 提示"需站在最后放置的磁盒上"）。

  • 异常处理：若最先放置的磁盒已消失（被回收/异常），顺延至次先放置的磁盒，保证激发链不中断。

  • 边界限制：磁盒组仅 1 个磁盒（无拼接）时激发，无相斥效果。

  • 边界限制：一次激发只影响一个磁盒组；若多个磁盒组共存，需分别激发。

  • 边界限制：激发瞬间磁极指定后不可撤回，回收计时立即开始。

4. 磁盒激发后回收

  • 自动回收：激发后 （0.5-1秒） 自动回收。

  • 强制回收时机：

    1. 玩家死亡 → 立即回收所有磁盒；

    2. 玩家传送（锚点 / 场景切换）→ 传送前强制回收所有磁盒。

  • 主动回收：H 键一键回收所有磁盒（见核心操作）。

  • 边界限制：回收为瞬时生效，无延迟。

  • 异常处理：正在被玩家攀爬的磁盒被回收时，玩家立即进入自由落体状态。

5. 相接磁盒激发后的推动

  • 相接磁盒组激发后磁极相同，互相推动。

  • 相接的磁盒组运动状态一致。

  • 推动方向：沿拼接时的接触面法线方向。

  • 边界限制：若磁盒被推至靠墙/障碍物，该磁盒停止移动，且其在推动方向上的速度归零。

修改
#

1. 磁盒数量上限调整

  • 调整：磁盒数量无硬性上限（可超过 5 个）。

  • 调整原因：

    1. 《Öoo》为 2D 游戏，只有 4 个移动方向，磁盒是 3D 的，有 6 个移动方向；+2

    2. 炸弹可以单独引爆提供位移，而磁盒至少要两个才能激化相斥提供位移；+1

    3. 《原神》的地图远大于《Öoo》，故需要更多的位移。2+2+1+n >= 5

  • 边界限制：磁盒数量达到性能软上限后，新生成请求被拒绝并提示"磁盒已达上限，请先回收"。

2. 水平推动速度衰退

  • 地面推动：水平速度快速衰退至 0。

    • 线性衰减。

  • 空中推动：水平速度衰退平缓。

    • 最小水平速度 = 滑翔水平速度。

    • 无论推动磁盒数量多少，最终水平位移一致。

  • 垂直方向：始终受重力影响。

  • 调整原因：《原神》的地图远大于《Öoo》，故需要更多的位移距离。

  • 边界限制：磁盒/玩家被推至碰撞体（墙、地形）时，该方向速度立即归零。

增加
#

1. 磁珠（收集物）

  • 磁性：拥有红/蓝两种磁性之一（生成时固定，不可变更）。

  • 物理：不受重力影响，固定悬浮于生成位置。

  • 碰撞：有碰撞体积，不可穿透地形/墙。

  • 磁珠拾取：

    • 异性磁盒进入 吸附范围内 → 磁珠被吸引向磁盒移动；

    • 同性磁盒进入 吸附范围内 → 磁珠被排斥推远（仍保持在吸附范围内）；

    • 拾取判定：磁珠接触磁盒表面 → 拾取成功。

  • 磁珠电场：

    • 电场范围：磁珠周围；

    • 效果：对进入范围的可攻击物造成雷属性伤害，并击退击飞；

    • 消失条件：任意磁盒进入电场范围 → 电场立即消失；

    • 目的：引导玩家使用磁盒拾取，避免直接靠近。

  • 边界限制：磁珠被推至靠墙时停止移动，推动方磁盒在推动方向速度变为 0。

  • 边界限制：磁珠不会被推出"附近"范围，系统约束其位置以保证可拾取性。

  • 边界限制：磁珠之间互不影响（磁珠间不互斥/不互吸），仅与磁盒交互。

  • 边界限制：磁珠电场只作用于"可攻击物"（怪物、玩家），不作用于磁盒以外的场景物。

2. 磁盒可攀爬

  • 玩家可攀爬磁盒表面（包括拼接组），用于登高/等待/调整站位。

  • 目的：方便玩家使用，避免垃圾时间。

  • 边界限制：攀爬中磁盒被回收 → 玩家进入自由落体。

  • 边界限制：攀爬中可执行激发操作（满足激发条件时）。

  • 边界限制：攀爬中磁盒不可被其他磁盒拼接（避免拼接打断攀爬）。

3. 磁盒不可推动

  • 磁盒不可被玩家、怪物、其他磁盒（未激发状态）推动。

  • 目的：避免垃圾时间，保证拼接精度。

  • 边界限制：唯一例外是激发后的相斥推动。

4. 拼接后磁盒组不会倾倒

  • 拼接组姿态固定，不受重力/碰撞影响而倾倒。

  • 目的：避免垃圾时间，保证拼接精度。

目标体验
#

  1. 规划磁盒拼接顺序与位置，以达到目标位置，其中的策略解密的乐趣；

  2. 不同于日常的更高性能的移动手段，快速长距离移动观察提瓦特（类似飞行、飙车、跑酷）带来的乐趣；

  3. 随拥有的磁盒变多，基于斥力的简单规则可以带来更具想象力的使用形式（例如，璃月直飞稻妻），带来创造与探索机制的乐趣。

附加机制
#

为更好地达成目标体验，添加如下补充机制：

1. 磁盒可在大地图任何地方使用（不局限于收集磁珠）

  • 那么，玩家为什么要去收集磁珠呢（除开解密乐趣）？

    1. 磁珠可以兑换奖励；

    2. 可以兑换更多磁盒。

  • 可用区域：提瓦特大世界所有可站立表面。

  • 不可用区域（进入时强制回收磁盒并禁用道具）：

    1. 秘境、副本内部；

    2. 深境螺旋；

    3. 任务过场动画/剧情演出期间；

    4. 周本 Boss 战等特殊战斗。

  • 边界限制：普通战斗中可使用，但磁盒不阻挡攻击（不可作为掩体）。

  • 边界限制：联机场景下，其他玩家的磁盒对自己不可见/不可交互（本活动为单人，避免干扰）。

2. 磁珠串（路径）

  • 磁珠可多个相连形成路径（类似跑酷中的金币）。

  • 串长度：3-15个 磁珠。

  • 串形成：磁珠生成时按预设路径排列。

  • 目的：

    1. 引导玩家拼接磁盒规划路径，熟悉磁盒的移动性能（一次相斥能移动多远）；

    2. 引导玩家一次性收集尽可能多的磁珠，提供更复杂的规划以满足进阶玩家。

  • 边界限制：磁珠串中的磁珠仍各自独立判定磁性/电场，串仅为生成时的排列形式，不构成额外机制。

边界与异常处理汇总
#

# 异常场景 处理方式 涉及机制
1 磁盒生成时玩家位于不可站立表面（水面/岩浆/毒沼） 生成失败，无磁盒出现 生成规则
2 磁盒生成时玩家处于空中/移动中（跳跃/下落/滑翔/疾跑/游泳） 生成失败，提示"需站立时使用" 生成规则
3 磁盒生成时涉水深度超过脚踝 生成失败 生成规则
4 磁盒被推至地图边界/墙/障碍物 磁盒停止移动，该方向速度归零 推动物理
5 磁珠被推至靠墙 磁珠停止移动，推动方磁盒速度归零 磁珠拾取
6 玩家在磁盒上/攀爬中死亡 所有磁盒立即回收，玩家正常复活 回收规则
7 玩家传送时磁盒存在 传送前强制回收所有磁盒 回收规则
8 磁盒数量达性能软上限 阻止生成，提示"磁盒已达上限，请先回收" 数量上限
9 激发时玩家不在最后放置的磁盒上 激发无效，可给 UI 提示 激发规则
10 最先放置的磁盒已消失 顺延至次先放置的磁盒 激发顺序
11 单磁盒激发（无拼接） 无相斥效果，仅触发回收计时 激发效果
12 摆放状态被击退/打断 自动退出摆放状态，取消预览 摆放状态
13 磁盒与 NPC/怪物重叠生成 生成失败或磁盒挤开 NPC，优先保证生成成功 生成规则
14 攀爬中磁盒被回收 玩家进入自由落体 回收/攀爬
15 进入秘境/副本/特殊战斗 强制回收磁盒，禁用道具 大世界使用
16 同性磁盒相邻 不拼接，无特殊效果 拼接规则
17 磁珠有被推出"附近"范围的趋势 系统约束磁珠不离开附近范围 磁珠拾取
18 被推动磁盒撞击未激发磁盒 不触发链式推动，被撞磁盒不动 推动物理
19 联机中其他玩家存在
 本活动单人，他人磁盒不可见/不可交互 大世界使用

玩法设计方案
#

持续时间：两周左右

参与人数：单人

玩法循环
#

观察信息（磁珠位置、磁珠串的路径）—— 规划（磁盒磁极属性、拼接位置与顺序）—— 反馈（获取磁珠：兑换奖励或磁盒；未获取磁珠：重新挑战）—— 新的磁珠循环

  • 具体机制见上文机制部分

核心操作
#

  1. 将小道具切换为磁盒，点击使用道具（默认是Z）进入摆放状态，再次点击则退出；

  2. 摆放状态可预览摆放的位置（类似刻晴的战技），点击鼠标进行摆放；

    • 有对齐吸附功能。

  3. 摆放状态时，滑动滚轮改变预摆放磁盒的磁极；

  4. 玩家站在或爬在最后摆放的磁盒上时，才能点击激发（F）；

  5. 一键回收磁盒（H）；

复玩性设计
#

  1. 活动期间每日会更新待收集的磁珠；

    • 但关键奖励不需要每天全收集才能兑换（避免利益驱动损害游玩乐趣）。

  2. 随玩家游玩活动，磁盒会越来越多，玩家可以进行的位移也越来越灵活，距离也更远，可以添加额外（第二周时）的高难度收集（例如，一次性收集15个磁珠的成就让玩家挑战）（详见体验1）。

  3. 除开收集磁珠，玩家使用磁盒在提瓦特各处穿梭探索，尝试各式得长距离移动，开发新路线（详见体验2、3）。

活动奖励
#

  • 通过收集的磁珠兑换。

  • 磁珠也可兑换磁盒。
