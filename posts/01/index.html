导言
#

1
#

  • 本文分为理论部分与应用部分。

  • 理论部分主要讨论组成工厂系统的机制与元素，以及它们在其中对于复杂度与驱动力的作用。同时，提出一套用于分析的工具，以便轻松地辨析出不同游戏的工厂系统设计差异与目的。

  • 应用部分将选择《终末地》的工厂系统，从中选取5个机制与元素，利用本文的方法论进行解析，以展示其在设计侧的应用潜力。

2
#

  • 理论部分分为四个小节。

  • 第一小节讨论工厂玩法对玩家的价值，通过与合成台比较，从中发现影响该价值的因素，并对系统方面的部分做出归类与分析。由此提出的两类复杂度，是本文所有分析工具的基础。

  • 这一小节的另一个作用是切断逻辑链条的终点。因为，对于构成玩法的系统而言，其设计目的，几乎都是调节影响决策与操作部分的系统的复杂度，从而增加最多部分的受众的吸引力。故在此将三类复杂度及其作用做统一说明，以保证后文具体机制分析的结论逻辑的简洁与差异性。

3
#

  • 第二小节讨论资源机制对于两类复杂度的影响。并提出三个维度来对资源的作用做定性与定量的分析。

  • 第三小节讨论效率机制对于两类复杂度的影响。并从中初窥两类复杂度之间的转换关系。

  • 第四小节将对理论部分做个总结。

4
#

  • 应用部分也分为四个小节。

  • 第一小节对电力与天有烘炉这两个资源机制做拆解，展示本文理论的易用性，并通过调节资源三维度，尝试设计出有意义的新资源。

  • 第二小节通过对比《终末地》、《异星工厂》、《戴森球计划》的传送带，展示对效率机制的解释力。

  • 第三小节通过对仓储机制的分析，展示本文理论对于发现设计缺陷的作用。

  • 最后，第四小节通过分析面积、进出货口等机制，总结出《终末地》工厂系统的设计倾向，并对之后的可能做展望。

理论
#

工厂游戏如何可能
#

从合成台到工厂要几步？
#

  • 合成台是一个相对简单的功能系统，其功能为将特定资源转换为另一些资源。这同样是工厂系统的核心功能。但是，前者为功能系统，后者是玩法系统。

  • 那么，究竟是哪些机制让同样用来转换资源的工厂系统具备了可玩性？接下来，我们一点点地添加机制，让合成台变成工厂，从而发掘出工厂系统的可玩性来源。

第零步：出发点
#

  • 作为转换资源的系统，根据配方（不同资源的不同比例）转换产品是理所当然的共性。而前一个的产品作为中间产物，成为后一个的原料，也是共同的要素。

  • 于是，我们不难发现第一的不同点：合成台需要一步步合成，而工厂可以直接从最初级的资源，自动合成需要的中间产物并最终达到合成目标。换言之，工厂是自动化的。

第一步：当真如此吗？
#

  • 事实上，许多游戏中（尤其是MMO）的合成台，在合成时，已经可以自动识别初级材料，帮玩家自动合成补充缺失的高级材料。

真 · 第一步：做完你的做你的……
#

  • 我们的直觉或许是对的，自动化确实是不同点，但不是作为结果的自动化，而是作为过程的自动化。换句话说，工厂需要玩家根据最终产品的配方，将合成各个中间产物的装置按比例组合起来，即规划产线的流程。

  • 那么该如何给合成台添加一个规划机制呢？一个做法是，玩家可以在界面中，通过拖拽，将用于合成各个中间产物的合成台，以积木或者UE蓝图的形式拼起来。拼好后，玩家只需点击合成，就可以直接从最基础的资源合成最终产品了。

  • 到此为止，我们的合成台做到玩家自行规划产线的目的。它已经从功能系统变成了可玩的系统了。我们也发现了工厂玩法的第一个乐趣：根据产品的配方，一层层选择安排装置及其数量与顺序，从而规划出一条直接从基础资源到最终产品的流水线。即逻辑规划的乐趣。

  • 但是，一个可以自定义的合成台，仍然与工厂有不少距离。最明显的差异是，工厂的装置之间是不可重合的，且放置的面积往往是有限的，因此玩家需要对装置的位置进行规划。也就是说，工厂需要空间规划。

第二步：就像海绵里的水
#
  • 合成台的空间规划机制，可以是要求玩家将选择好的各个合成台，放置到一个限定区域，类似于拼图或七巧板。
  • 此时，合成台的策略性进一步丰富（一个地方，放了甲就放不了乙，那怎么放、放谁呢）。我们也发现了工厂玩法的第二个乐趣：玩家需要根据产线和其他产线的装置，考虑规划装置的位置，使其不冲突。即空间规划。
第三步：为什么要引入时间？
#

  • 时间几乎是现在与工厂唯一的区别了。但比起“是否”，“为什么”是更有意义的问题。

  • 逻辑规划与空间规划带来的策略性上的游戏性是显而易见的，那时间又带来了什么呢？从数量配平到速度配平吗？显然不是，二者没有区别，玩家之前怎么搭产线，之后还是怎么搭。

  • 但是这里有个华点：“玩家之前怎么搭产线，之后还是怎么搭。”也就是说，时间带来的并不是策略性上的变化。那变化来自何处呢？

  • 让我们回到工厂系统的流程，采集——规划——搭建——反馈。策略的乐趣除了规划过程，其结果同样重要。逻辑规划与空间规划对应着规划、搭建的过程性乐趣，而时间对应的便是结果反馈。

  • 换句话说，时间改变了反馈的节奏。这有什么用呢？

  • 我们先来看看合成台的情况。玩家确定目标产物后，进行逻辑规划与空间规划，然后使用合成台，立刻获得结果。之后玩家就要确定新的目标，如此循环。工厂与之唯一的区别是，玩家是逐渐获得结果的（是否能跑通、是否能满速跑通、获得足够数量）。

  • 两种情况看似相差无几，玩家的体验却区别巨大。要知道，逻辑规划与空间规划是思考的过程，虽有乐趣但并不算轻松；完成的反馈是无需劳作的，是一种成就感。换句话说。规划是有负担的，完成一个立刻去完成下一个是令人相当疲倦的。也就是说，完成从一件成就感的事，变成了一种带来短暂快感和长期压力的事。（说的就是你《图灵完备》）

  • 而引入时间将完成的成就感分散，虽然减弱了一时的激励，但同时也缓解了下一次搭建循环带来的压力。简单来说，时间的作用便是避免长时间的规划与快速的反馈不对等，通过延长反馈时间来缓冲下一次规划的心智负担。

小结：工厂系统的核心乐趣在于逻辑规划与空间规划的策略性，以及相对缓和的节奏。

尾声
#

  • 除了引入时间将反馈与下一步延长，工厂游戏往往以规模庞大的流水线画面来加强完成时的成就感激励，这也是对冲压力的一部分。

  • 最后，如果某个游戏选择工厂而非合成台，目前我们至少可以得出，这是想通过添加逻辑规划与空间规划的策略性，吸引可以被策略性讨好的玩家。

工厂的吸引力
#

  • 上一节我们谈到了工厂系统的核心乐趣是逻辑规划与空间规划的策略性；还提出了工厂系统的基本循环：采集——规划——搭建——反馈。其中，策略性主要在规划与搭建这两个环节展现。

  • 接下来我们将要探讨并总结出，工厂系统是如何影响自身的策略性的。

策略性与复杂度
#

  • 工厂游戏的策略性主要受其逻辑规划与空间规划的复杂度影响。
前置知识
#

  • 众所周知，工厂游戏的策略性与乐趣并非完全正相关的（不然设计芯片就是世界上最有趣的游戏之一）。它们的关系大概如下。

  • 对于不同的玩家，乐趣峰值对应的策略性是不同的。而在整个玩家群体中，乐趣峰值对应的策略性的值，和对应的玩家数也大致是正态分布的。换句话说，均值附近的策略性可以使大多数玩家获得接近于峰值的乐趣。而极难与极易只能满足少量玩家。

  • 而到底什么样的难度是合适的，只能通过测试与具体的数据判断。（根据观察，比《戴森球》难或者比《终末地》简单，大概就开始下降了）

复杂度的两个维度
#

  • 工厂游戏的复杂度可以分为两个维度：空间复杂度、逻辑复杂度。

  • 空间复杂度：指单位空间内玩家需要摆放的装置与传送带数量，即玩家空间规划的难度。主要受面积、出口数、入口数影响。其中出入口数，取决于配方的复杂度和产线的长度。

    • 出入口数越多，传送带越多。而入口越少，传送带就不得不越近，等同于面积变小。

    • 当入口数不变时，随出口数增加，复杂度的增长是指数的。

    • 以图示为例：a > (c+b) > 3c

  • 逻辑复杂度：即配平，以及当资源有限时，优先生产哪一个产品。（例如，先产电池，等攒一波电，之后可以快速铺产线，但当下没有产品；或先铺产线，当下产量上升，但电量不足时必须回头产电池。）

    • 一个产物的配方复杂度，随次级材料的种类增加而增加，但这增长是线性的。

    • 以图示为例：a = (c+b) = 3c

小结：工厂系统的机制主要围绕着对这两类复杂度的调整而设计，进而改变系统的策略性（之所以要改变策略性，详见前置知识）。

工厂系统的机制概述
#

工厂系统主要由两部分组成：资源机制与效率机制。

  • 所谓资源机制，即资源性质、资源的使用、分配，以及资源间转换的规则。

    • 玩家需要权衡有限的资源（给甲多一点，那么乙就少一点），将其合理（甲的收益，多于乙的损失）分配。

    • 设计者则可以通过调整资源的性质与关系，改变逻辑与空间复杂度。

  • 效率机制指，使资源获取、转换效率改变的规则。例如，传送带、不同发电量的电池等。

    • 效率机制为玩家提供了，调整转换逻辑与空间复杂度的手段。

    • 设计者则可以通过提供不同的效率机制，引导玩家行为。

资源机制
#

  • 接下来我们将拆解资源的性质，并探讨它们的意义，以及如何影响逻辑与空间复杂度。

资源的三种性质
#

  • 资源的性质可以被分为三部分：外部依赖、内部依赖、参与度。
内部依赖
#

  • 内部依赖指，是否需要次级产物合成加工。

  • 内部依赖可以得到该资源的成本，及生成它的消耗；而没有内部依赖，则证明它是基础资源。

外部依赖
#

  • 外部依赖指，产量是否受资源以外的条件限制。

  • 当某个资源拥有外部依赖，那么可以通过调节外部依赖，从而简单地调控相关产线的产量。换句话说，如果想要调控某系列产线的产量，可以给其中的某个资源加上外部依赖。

  • 在大部分游戏中，外部依赖等价于游玩的时间或者说进度。在达到地图全开发以前，基础资源的上限，往往取决于玩家探了多少图、是否建了足够的开采装置，而非《终末地》里天有烘炉的直接限制。

  • 不过，严格来说，天有烘炉的直接限制也是进度的体现，可以等价于《异星工场》中把星球探完了。

  • 换言之，外部依赖资源是作为短期驱动力，通过限制产量来吸引玩家推进进度，来提高其上限。也因为它限制了产量，玩家也必须对其的分配加以考量（给甲多一点，那么乙就少一点，甲的收益，多于乙的损失）。

参与度
#

  • 参与度指，存在于多少个配方之中。

  • 参与度衡量了某个资源对产线难度的影响。这是显而易见的，当产线的配方中的资源种类变多，意味着需要配平、空间规划的量变多了，难度自然上升了。反之亦然。

基础资源
#

  • 从上文我们知道了基础资源是没有内部依赖的资源。这意味着，我们可以将任何产线翻译为基础资源的和，再通过比较基础资源的大小，就可以判断出一条产线的复杂度。

  • 值得一提的是面积，它跟其它基础资源有显著差异。

    • 首先它是唯一影响且只影响空间复杂度的基础资源。

    • 其次，虽然大部分上级资源对应的面积是固定的，但像传送带对应的面积资源是可变的。这意味着，每一条产线的空间复杂度还会受可建设区域面积，以及与其他产线的位置关系影响。

效率机制
#

  • 效率机制可以被分为四类：基础型、转换型、优化型、增长型。

基础型
#

  • 基础型指构成流水线的基本框架的机制，如采集、传送、转换、存取等，缺少任意一个都会使系统无法运行。

转换型
#

  • 转换型可以将一种复杂度转换为另一种复杂度。

  • 例如，高速传送带就是通过增加逻辑复杂度，来降低空间复杂度。

    • 换句话说，玩家在决策如何安排装置与传送带时，可以通过消耗额外的脑力，选择不一样的传送带，来节省空间资源（如图）。
    • 同时，传送带、分汇流器与装置的组合，可以获得各式不同效率的装置集（如图所示）。这是装置层面的涌现，通过增加逻辑复杂度，用较少的元素，大大丰富了产线的探索空间。

  • 一般而言，因为空间复杂度的增速远高于逻辑复杂度（详见复杂度的两个维度），所以大多数转换都是，通过增加逻辑复杂度来降低空间复杂度（只是想增加难度的话，往往使用增长型）。

优化型
#

  • 优化型指单纯降低复杂度的机制。某种程度上（总复杂度降低），转换型也可视作优化型。

  • 例如，蓝图、无线采矿机等。

  • 偷懒是人的本性，所以优化型往往也作为一个个中期目标，来驱动玩家推进游戏进度。

  • 和大部分转换型一样，优化型也有为新的产线或增长型的引入，预留难度空间的作用。

    • 正如前置知识中提到的，乐趣随策略性变化是存在峰值的。而随着玩家游戏的推进，其游戏水平是在提高的，也就是说，策略性在下降。

    • 为了维持乐趣峰值，便需要加入更复杂的产线，而正如空间复杂度中所言，其复杂度是指数级上升的。因此，在引入更复杂产线时，往往会有配套的优化型与转换型的引入，让难度增长相对平缓。

增长型
#

  • 增长型通过加长产线产出更高级的产品，或引入新的产线，从而增加复杂度。

  • 其作用在优化型中已提及不再赘述。

总结
#

  • 工厂系统的乐趣来自于空间规划与逻辑规划，它们又受空间复杂度与逻辑复杂度影响，且与乐趣大致呈正态分布。

  • 工厂系统中的资源机制可以通过外部依赖、内部依赖、参与度，来判断其对复杂度的影响；效率机制根据对复杂度的影响可以分为：基础型、转换型、优化型、增长型。

补充：目标
#

  • 上文中零散地提及了系统流程中的各类目标，特在此处归纳。

  • 短期目标：获取限制着产能上线的拥有外部依赖的资源。

  • 中期目标：获得可降低复杂度的转换型或优化型效率机制。

  • 长期目标：最终产物（根据游戏不同而不同，戴森球、火箭、发展券等）。

应用
#

电力与天有烘炉
#

电力
#

  • 电力属于资源机制，所以我们可以从资源机制的三性质入手分析。

    • 内部依赖：有。说明电力不是基础资源。这与我们的第一印象是有所差别的，因为在游戏中电力的影响无处不在，不亚于面积与基础矿物。

    • 外部依赖：无。

    • 参与度：除了发电以外的所有配方。

      • 这就解释了，为什么我们会在第一眼将其误认为是基础资源。电力的参与度高得离谱，所以一旦不需要考虑它，整个工厂的产线复杂度会陡降，反之亦然。
高级电池
#
  • 高级电池及产线属于增长型和转换型，引入了更复杂的新产线，但相同发电量下需要间的产线规模下降了，所以也属于通过增加逻辑复杂度来降低空间复杂度。

天有烘炉
#

  • 天有烘炉属于增长型，引入了更复杂的新产线（息壤系列）。

    • 让逐渐掌握工厂玩法的玩家，拥有更具深度的内容（维持乐趣峰值）。

    • 同时，进一步培养了玩家该玩法的能力，为之后工厂玩法的拓展奠定玩家基础。

息壤
#

  • 息壤属于资源机制，所以我们可以从资源机制的三性质入手分析。

    • 内部依赖：有。

    • 外部依赖：有（最多12个装置）。引入新的外部依赖资源息壤及天有烘炉，相当于增加了新的可推进进度，而息壤及天有烘炉就是其中的短期目标。

    • 参与度：相关系列产品。

再论时间
#

  • 在前文我们谈到，时间在工厂系统中的核心作用是调节节奏。如果只看参与度的话，它甚至是超过了电力，但时间仍然不是有意义的资源，它对复杂度并未产生影响。

  • 接下来我们将使用资源机制三性质与效率机制的类型，为时间提供有意义的设计思路。

  1. 将外部依赖变为有。在一般工厂游戏里，时间是取之不尽的。所以最简单的改动便是限时，让玩家分配有限的时间完成某个产量要求（是的，工厂游戏也可以排轴），此时空间复杂度和逻辑复杂度因时间的限制都会上升。

    1. 或者完善一点，即《异星工厂》的虫子机制。维持设备运行时间，即避免被虫子破坏。
    • 但是我们不能忘记时间作为缓和节奏的作用，且不论会退回之前讨论的超级合成台，高策略高操作本身也是在挑战人体机能极限（RTS尸骨未寒）。

  2. 引入时间相关的增长型或转换型效率机制。

    • 例如，《戴森球计划》等科幻背景的游戏，可以引入相对论元素，即不同区域的时间流速有差异（将逻辑复杂度转化为空间复杂度，同一产线在不同位置效率提高），或者能产生时间流速差异的产线（增长型和转换型）。

《终末地》、《异星工厂》、《戴森球计划》的传送带比较
#

机械臂
#

  • 《异星工厂》的机械臂无疑是最明显的差异。显然，属于效率机制中的基础型。也就是说，《终末地》、《戴森球计划》使用的是优化型（减少了机械臂摆放和使用的逻辑与空间复杂度）。

  • 对《终末地》、《戴森球计划》无疑是为了降低前期的上手门槛，尤其是对《终末地》的泛二次元游戏用户来说。

高级传送带
#

  • 另一个区别则是《终末地》只有一种传送带。高级传送带作为转换型效率机制，其作用在转换型章节已经提过。

  • 就《终末地》而言，高级传送带作为增长型配套的转换型机制，并不存在相应的高级产线需要提供复杂度的预留空间。

    • 单纯地引入高级传送带，降低了空间复杂度不说，逻辑复杂度的提高对轻中度泛二次元游戏用户来说是十分明显的。因为，同等情况的复杂度，空间复杂度更容易让人接受的，比起抽象的计算，可视化的规划更容易让人接受（这也是为什么，在多数时候，明明写代码更方便快捷，UE还是有很多人用蓝图）。

仓库、垃圾桶与自动销毁
#

前置知识2
#

  • 仓库属于基础型。同时，它的爆仓机制作为负反馈，让玩家返回去研究产线的消耗配比，或新建仓库（因为消耗它的其它产线还未搭好，需暂时储存），或新建修改产线将其消耗，让产线越发高效，同时让玩家对游戏的理解加深。

  • 垃圾桶属于转换型，减少配平的逻辑复杂度，增加摆放垃圾桶的空间复杂度。

自动销毁的总仓库
#

  • 《终末地》的总仓库是将仓库与垃圾桶集成在一起的产物。仓库本身是基础型，但吃到了垃圾桶的转换型的效果。所以，相对于前两者，它是一个优化型（作用不言而喻）。

  • 虽然仓库的负反馈效果消失了，产业报表（可以看到个资源的消耗与产出）却弥补了这一需求。

远程仓库
#

  • 而远程仓库也属于优化型，却没有自动销毁的功能，即保留了仓库负反馈的功能。

  • 而我们知道，这一功能已经被产业报表实现了。所以远程仓库的负反馈成了负面反馈，唯一的作用在于，远程仓库的爆仓可以提供一个问题产线的比较精准的位置。

  • 所以，我们可以设计一个更好的远程仓库。很简单，添加自动销毁。触发时显示警告，直到下一次传送不触发自动销毁时解除。并且可以手动关闭，再次开启时的默认状态为无警告。

《终末地》的工厂是怎么控制难度的？
#

面积分散
#

  • 乍一看，可建设面积分散似乎在限制长产线以降低空间复杂度。而事实上，产线是模块化的。工厂游戏的一个技巧就在于，将中间产物的产线视作一个个模块，这一个个模块根据比例拼接，从而实现复杂的流水线的搭建。

  • 所以，将可建设面积拆分，便是暗中要求玩家进行这种模块化的搭建。换句话说，当一个地方放不下一个复杂的产线时，玩家自然地就会将其拆分为中间产物组成的模块，放在不同的区域中。

总仓库与限制进出货口
#

  • 将面积限制与进出货口限制结合起来便能发现其中的秘密。

  • 让我们先看看《异形工厂》。

  • 前文我们讲过，出入口数会影响空间复杂度，而总仓库的存在即是对出入口数以及位置做限制，从而限制产线的起点与终点，以提高空间复杂度。

  • 而此时再将面积加以限制，高空间复杂度也会进一步提升。

  • 那么为什么要如此专门地提高空间复杂度呢？

    • 答案之前提过，即比起抽象的计算，可视化的规划更容易让人接受，即同等情况的复杂度，比起逻辑复杂度，空间复杂度更容易让人接受。尤其是目标用户是中轻度的泛二次元游戏的《终末地》。

  • 所以，无论是出入口数限制，还是面积限制，都是在控制产线的长度与各级资源的种类，以减少逻辑复杂度的同时，保证空间复杂度，以维持乐趣（对于中轻度玩家）的空间复杂度优先的设计思路。

展望
#

  • 基于对《明日方舟》发展的观察，可以推测：

    • 目前工厂系统的设计，是在尝试将非受众培养为受众，将中轻度玩家培养为硬核玩家；并在之后推出，更具深度的工厂玩法，通过游戏性将这部分玩家变为高粘度的玩家，从而形成稳定的高质量用户群体。

    • 合理怀疑是在复刻《明日方舟》的路线，即逐渐培养出中度和硬核塔防玩家群体，再以深度带来的游戏性维持高粘度。

  • 进一步推测这个可能的深度工厂玩法

    • 分散的可建设区域与工厂游戏的复杂产线是十分融洽的。

    • 从跨区域传送物资的限速（因为如果只是为了避免新地图的发展券泛滥，限次显然是更爽快的方式）来看，一个极庞大的产线，可以是每个区域承担一个中间产物的区域间的合作。
