分享传播的内容设计分析
#

分享传播的内容设计及优缺点
#

UGC
#

  • 分享的原因：

    1. 作为自我的表达，需要被看到来确证；

    2. 通过展示造物，来获得认可。

    • 内容的可复制性，成为他人认同的来源基础。

  1. 岛建与房间装扮

    • 设计目的（分享侧；后文无特殊说明，皆仅关注分享侧作用与缺点）：通过预设物件的组合（门槛较低），让相对更广泛的玩家可以参与创造分享。

    • 缺点：操作不便，只能以角色的位置来放置物品和改变地形，对于批量、大范围、精确位置的操作十分麻烦（需要频繁移动调整角色位置）。【但这也是真实感的来源之一，不过就分享来说，加大了分享内容制作的难度，无疑是分享上的缺点。】

  2. 服装、画与地砖

    • 设计目的：

      1. 提供更自由上限更高的可创作内容，从而有更多、更高质量的传播内容以活跃热度；

      2. 二维码复制，为游戏本身提供源源不断的更多物品内容，供所有玩家使用；

      3. 为具有能力与意愿的深度玩家提供更丰富、灵活的表达手段。

    • 缺点：

      1. 对不具备相关技能（绘画、设计等）却有意愿的玩家，缺乏教学或其他手段，只能通过游戏外的自行学习，门槛极高。

      2. 相关内容分享高度依赖一小批创作者，不稳定（一旦他们退坑或兴趣下降，相关内容便消失了）。

  3. 拍照

    • 设计目的：操作简单，让大部分玩家都能参与创作分享。

    • 缺点：缺乏构图辅助，出片质量参差。

  • 共同优势：

    1. 玩家自发创作，不额外消耗产能。

  • 共同缺点：

    1. 操作不便，Switch需截图、退出游戏、进入相册、传到手机、发社交媒体，操作过多。

    2. 外部的社交平台无法精准搜索自定义图案等内容，分享者收到的反馈也不稳定（老内容随时间沉底）。

小动物表现
#

  • 分享的原因：通过将触动自己的小动物互动与故事分享，期望获得情感上的确认与认同（有趣、感触等）。

  1. 任务事件（搬家、生日、探病等）

    • 设计目的：

      1. 通过玩家都经历过的被精心设计的事件，让玩家之间形成体验感情上的共鸣，从而增强玩家在游戏里跟小动物的故事与互动中获得的情感联系与体验。而情感受到认可（精心设计的同样的桥段往往会激起相似的情绪，共鸣是大概率事件），又会进一步加强分享欲。

      2. 激发玩家的情感，从而使玩家分享（因为人往往愿意分享触动自己的经历）。

  2. 随机事件（吵架、唱歌、晨跑等）

    • 设计目的：

      1. 无需进行较长的任务、甚至无需有玩游戏就可以理解其中的趣味，从而广泛传播（玩家、非玩家）；

      2. 玩家不经意间看到有趣场景，激起分享欲（渴望情感或者幽默感被认可）。

  • 共同缺点：

    1. 同上一部分。

    2. 后期重复度高，不再吸引触动玩家。

资源差异
#

  • 分享的原因：

    1. 炫耀；

    2. 资源互补，满足被需要的感觉。

  1. 稀有物品

    • 设计目的：炫耀。

    • 缺点：老玩家之间，对于稀有物品的差异微小，无炫耀价值。

  2. 大头菜、初始岛屿资源差异

    • 设计目的：通过分享与他人不同的资源、或者更高、更低的大头菜价格，以招徕其他有需求的玩家，从而满足被需要感。以此促使玩家分享。

    • 缺点：游戏后期资源差异被抹平，也不缺钱（倒大头菜的动力下降）。

  • 共同缺点：

    1. 同第一部分。

    2. 无法持续至游戏后期。

季节与节日
#

  • 设计目的：

    1. 与现实话题同步，成为可以在更多场合分享的内容。

    2. 对日常的内容进行改变，变化是天然的分享话题。

  • 缺点：每年会重复，新鲜感会下降，进而对变化麻木而减少分享。

优化思路
#

  • 分享与传播主要分为三个部分：内容、手段、平台。接下来会从这三个方面提供优化的思路。

内容
#

  1. 为服装、地砖等自由设计功能，添加AI辅助设计（通过提示词生成），以便让更多的玩家可以参与其中，大大增加分享的内容量；同时，提示词本身也会成为分享内容之一。

  2. 小动物的随机事件和任务当然越多越好，但考虑到产能，为小动物配置玩家常用的功能和话语更加有性价比。

    1. 一方面更频繁的互动与帮助，更容易让玩家投入情感（如，防火女、西施惠等），促进分享与接受相关信息的需求。

    2. 这样的功能和话语还可以成为玩家间的共同语言或梗（如，“向着星辰和大海”、“不是鱼露，是鲈鱼哦”等）来分享传播。

手段
#

  1. 在手机端添加一键分享功能，避免过于繁琐的操作让玩家望而却步。

  2. 小动物的随机互动以及关键任务情节的CG，可以自动保留影像，避免玩家想要分享却玩家截图或录屏而放弃分享。

平台
#

  1. 内置创意工坊（支持搜索、标签、热度排序、收藏、评论、关注等），让创作者可以获得足够的反馈，也让更多的玩家方便地查看内容（从供需两端促进分享）。

  2. 分享直接接入平台（如米游社）无需退出游戏界面打断体验，进一步降低分享的门槛。

激励
#

  • 激励是一把双刃剑，过于真实的奖励往往会将分享的动机，从情感的需求变成利益的驱使。从而导致买量拉票等影响分享内容质量的行为，导致分享社区的慢性死亡。

  • 故，激励应以情绪价值主：点赞功能、优质创作者给予成就或称号；

  • 或者奖励的门槛放低：“分享1次内容”“点赞3次”等作为日常周常的可选项（避免强制分享）。

素材岛玩法设计分析与优化思路
#

玩法简述
#

  • （还清5,000里数债务后）玩家消耗2000里数兑换机票使用，从20个岛屿中随机选出4个岛，玩家在从中选择一个前往。岛上可能有：

    1. 基础资源（石头、树、杂草、鱼、虫）

    2. 非本地资源（树、花、竹子）

    3. 稀有资源（稀有花虫鱼、金矿、化石、漂流瓶）

    4. 小动物

  • 或者（完成前置任务后）消耗1000里数坐船，随机前往一个岛屿，与坐飞机不同的是：

    1. 没有小动物

    2. 有一个陶俑

    3. 季节时间可能错位

    4. 新版本的资源（发光苔藓、食材等）

    5. 每日只能坐一次船

设计目的
#

为什么要先还债/做前置任务
#

  1. 避免新手玩家在还不熟悉游戏的核心玩法（收集、建造、小动物）前，面对过多系统而产生迷茫和压力；

  2. 刚好处于玩家开始需要大量资源建造物品（本岛的资源不足以支撑），符合玩家的需求更流畅地吸引玩家体验素材岛玩法。

  3. 玩家在还债过程中已自然掌握了伐木、采集、钓鱼、捕虫等基础操作，素材岛开放时玩家已具备基本行动能力，能有目的地收集而非茫然无措。

为什么要引入坐船，而不是直接增加飞机可以去到的岛屿
#

  1. 若岛的种类变多，那随机到想要去的岛的概率会下降，玩家迟迟随机不到会产生挫败感；

  2. 若因此修改飞机随机岛屿的机制以适配更多的岛屿种类，

    • 对新版本回流玩家而言，老机制的修改带来的陌生感，要大于新鲜感，从而产生畏难情绪；

    • 对老玩家而言，修改熟悉的机制，会打破一直以来的习惯，这与游戏的核心体验（轻松、安稳的生活）相违背。

为什么坐船有次数限制
#

  1. 避免内容被过快的消耗掉；

  2. 通过每日的限制，变相将它变成每日必做的日常。

岛屿随机的作用
#

  1. 提供抽奖般的惊喜感；

短期驱动力
#

  1. 游戏前期建设对于基础资源需求；

  2. 非本地资源获取：素材岛可获得本岛没有的水果、花卉、竹子等，用于丰富本岛生态。

中长期驱动力
#

  1. 邀请小动物；

  2. 博物馆收集；

  3. 稀有物品的收集。

不足
#

  1. 游戏后期资源溢出，大多数岛屿仅提供垃圾时间；

  2. 单纯的收集物品变得单调枯燥；

  3. 岛的种类有限，当玩家都见过后，抽奖的惊喜感会消退。

优化方案
#

  1. 分层岛屿：增加高级里程票（消耗 5000/10000 里程），对应稀有岛屿类型（稀有虫鱼岛、特殊地形岛），给中后期玩家更高价值目标，避免低价值岛屿的垃圾时间；

  2. 限时活动岛屿：根据现实季节节日生成主题岛，增加变化性和时效感，延缓全见过后的惊喜消退；

  3. 解谜岛：部分岛屿包含小型解谜，丰富操作，缓解单纯采集的枯燥重复；

  4. 岛屿标记：可标记岛屿，二次访问需消耗双倍里程，让玩家在前往时取舍：是花较少的里数，随机前往岛屿，还是用更多的里数，去往标记的岛岛屿。

  5. 合作探索：支持组队前往素材岛，增加社交粘性。

免费模式下
#

  1. 次数限制与体力机制：限制每日去素材岛的次数，控制资源产出节奏，避免内容消耗过快。

  2. 长线内容供给：免费模式需持续供给新岛类型。

大头菜玩法设计分析与手机平台设计优化思路
#

玩法概述
#

每周日上午可以从曹卖处无限制购买大头菜（价格在90-110铃钱之间），接下来周一至周六，每半天价格变动一次，在下周日大头菜会腐烂无法再买。不同人的大头菜卖出价格不同，可以去好友处售卖。

核心循环
#

购买（信息：大头菜售价，拥有的钱；决策点：买不买大头菜，买多少大头菜？是将钱直接用于岛建，还是冒风险炒大头菜赚更多钱？）

—— 判断（每次更新价格时（含好友的价格），若亏了：是卖掉及时止损，还是赌它之后会涨；若赚了：是见好就收，还是赌它之后还涨。）

—— 结算（亏了：是金盆洗手，还是下次再来；赚了：是见好就收，还是再接再厉）

核心体验
#

  • 确定投入结合随机结果（且有可能获得暴利）的赌博心理；

  • 同时在好友价格很高，或自身亏本的情况下，提高对社交的需求；

  • 自身价格高时，分享炫耀，并在他人进入自己岛屿售卖时收获被需要的感觉。

社交与经济系统
#

  1. 价格差异与跨岛出售可以为大头菜的价格一定程度上兜底，甚至拔高。鼓励玩家分享与收集各自岛的价格。

    • 各自价格的不同与未知为交流提供信息，赚钱的兴奋与渴望、亏钱的恐惧为交流分享提供情绪动力。

  2. 炒大头菜可以快速获得大量铃钱，铃钱贬值迅速，相关内容快速消耗。

大头菜玩法在手机平台设计优化
#

差异
#

  1. 需要长时间的可玩性与动力；

  2. 需要维持铃钱价值（最终产物铃钱要有价值，但炒大头菜会使其贬值）。

  3. 手游玩家游玩时间碎片化，需适配异步社交。

思路
#

  1. 无需好友在线，即可前往好友岛屿卖大头菜。

  2. 限制采购上限，控制获取铃钱的上限

    • 问题：

      1. 基于跨岛采购大大提高了赚钱的概率，若控制了采购上限（失去大额收益带来的刺激与吸引），大头菜玩法就变成了每周获得固定收益的纯劳动玩法；

      2. 限制玩家的目的过于明显强硬，玩家会感觉被惩罚了。

  • 《星布谷地》（我是云的，没有测试资格，可能有误还望见谅）的做法有参考的意义：

    • 玩家售卖的是自己种植的作物（而作物成长需要时间，种植地也有限制），自然地限制了可售卖物的数量，解决了问题2；

    • 而取消作物腐烂的机制，降低了风险以对应被降低的收益。

  • 但是，问题1（本质上就是差异1）仍未解决。

    • 回看大头菜玩法，其乐趣之所以成立，是其资源循环是自我完备的，即：买大头菜——卖了赚钱——买更多大头菜——赚更多钱……

    • 而《星布谷地》式的大头菜玩法，其资源循环并不在自身玩法中（种地——卖作物赚钱——其他地方花钱），因此“种地——卖作物”本身变成了手段而非目的（原始的“买大头菜——卖了赚钱”既是手段也是目的），大头菜玩法也迅速沦为劳动而非乐趣。

  • 怎么办呢？

    • 思路也很明确：让资源能够反哺“种地——卖作物”这一循环；同时这一反哺不可以铃钱贬值为代价。

    • 那么，不以利益驱动，情绪驱动便是不二之选：

      1. 通过炒大头菜获得一定数量铃钱后，解锁雇佣机制（每周消耗一定铃钱），可以雇佣小动物帮玩家种菜；

2. 之后，随玩家达到一个个铃钱里程碑，可以雇佣小动物收菜、卖菜、买种子等；

    - 关于种菜：玩家可以指定接下来种什么（也可以随机自行安排）？

    - 关于卖菜：每次价格变动，小动物提供当前最高价（含好友价格）询问是否卖出？

        - 也可以设定期望价格托管给小动物（当第一次遇上超过期望价格时卖出）

  • 原因：

    1. 因为就本质而言，这以玩法只能是每周提供固定收入的系统，最后变得无趣是不可逆的（无论是后期玩家不差钱，还是对这一系列重复操作厌倦），所以以简化操作为驱动，吸引玩家游玩（偷懒是人的天性）。

      1. 既可以延长玩法的有趣游玩时间；

      2. 又为之后新玩法留出时间与精力；

      3. 丰富了玩家与小动物的互动与情感；

      4. 同时，对于社交上的作用也保留了下来。

赶海玩法活动设计
#

目标体验
#

  1. 没有进度压力的轻松感；

  2. 维持趣味，避免重复感；

  3. 与好友协作互动完成收获的乐趣；

  4. 结束后意犹未尽，对下次活动产生期待。

设计思路
#

放置与自动化
#

  • 赶海玩法作为活动玩法需要面对几个问题：

    1. 操作和策略简单，不适合连续投入较多时间（活动持续期间反复游玩将变得枯燥）；

    2. 游戏整体基调悠闲写实，不适合改造为割草玩法（一抓抓一片）——与日常赶海差异过大，刺激过于频繁，反而破坏轻松感；

    3. 增加海岸生物的个体机制（像《星布谷地》的木头人龙虾）不能太多：

      1. 学习成本过高（短时间内学习太多机制）；

      2. 每个海岸生物都有机制的话，玩家游玩起来会更累（且当玩家熟悉机制后，只是延长了收获的时间，仍是机械劳动）。

  • 基于以上问题，在玩家对新海岸生物赶海感到无聊前，引入邀请小动物帮忙一起赶海，并随活动进度邀请更多，以达成无需玩家自己赶海（类似放置游戏，每天登录收菜）即可拿满活动奖励。【目标体验1、2】

协作
#

  • 引入需要两人及以上才可以捕获的海岸生物，同时为避免强制社交，可以让小动物替代；

  • 邀请好友共进晚餐分享增益（详见晚餐部分）。【目标体验3】

沉淀与期待
#

  • 作为生活模拟类游戏，其体验往往要通过可摆放穿戴的物品沉淀下来——尤其是弱刺激的休闲玩法（采集）与慢节奏的经营玩法（种田），不止于多巴胺的来去。

    • 除活动服装家具外，赶海所在岛屿会有专门的度假小屋（可以用活动代币扩建、装饰等），在活动结束后便不能使用，但仍可以看到（小动物也会在路过时提起赶海活动）。

  • 除度假小屋带来的对下一次活动的期待外，活动中每日的晚餐可以在第二天给予增益，以提高玩家对第二天的期待。

  • 此外，根据邀请的小动物不同，满足一定条件后（例如抓一定数量的某个海岸生物，或晚餐有某个料理），可以触发专属奇遇剧情，提供额外体验，并让玩家渴望其他小动物的奇遇剧情，从而期待下一次赶海活动。【目标体验4】

核心机制
#

合作赶海
#

目的：在轻松基调下提供社交协作的乐趣，同时避免强制社交。

  • 协作生物：单人难以高效捕获的海岸生物。例如：

    • 蟹：

      • 一般状态下，警戒范围为自身周围一定范围的圆；

      • 玩家进入警戒范围后进入警戒状态；

      • 警戒状态下，永远与触发警戒的玩家保持距离（有多个角色时，以最近的为准），警戒范围变为前方120°的扇形；

      • 玩家离开警戒范围后一段时间，变为正常状态；

      • 抓捕时需要另一位角色，在警戒范围外靠近抓捕。

    • 鱼：

      • 存在于几个相邻的沙坑处，可钻入沙坑并从另一个钻出；

      • 一般状态下，警戒范围为自身周围一定范围的圆；

      • 玩家进入警戒范围后进入警戒状态；

      • 警戒状态下，立刻钻入沙坑并从另一个钻出，并变为一般状态，且数秒内无法进入警戒状态；

      • 抓捕时由于玩家不一定可以在冷却时间内跑到它出现处，故多名角色共同抓捕效率更高。

  • 小动物替代：未组队时，已邀请的小动物可充当协作伙伴。

  • 共享收获：组队捕获的生物共享，双方均获得进度与活动代币，避免竞争。

度假小屋
#

目的：将活动体验沉淀为可见的物品，制造活动结束后的期待感。

  • 位置与初始状态：赶海岛屿上的固定建筑，活动开始即开启，初始仅一个房间。

  • 扩建与装饰：

    • 随赶海获得的代币累积，到达一定里程碑后，逐渐解锁更多房间；

    • 每个房间可邀请一个小动物；

    • 家具来源：活动任务奖励、代币累积奖励、奇遇解锁等（只可用于度假小屋）。

  • 活动结束后：小屋变为关闭状态，可外观浏览但不能进入互动。小动物经过时会触发闲聊台词（例如，“还记得那次赶海吗……"），持续唤起记忆。

小动物协作
#

目的：以渐进式自动化解决重复劳动问题，将玩家从机械收集中解放，使其专注于有趣的部分。

  • 解锁节奏：第1周可邀请1个，此后随房间解锁增加，最多可邀请5个。

  • 分工与特长：不同小动物擅长捕获不同类型的生物，玩家需根据当日目标合理指派。

  • 工作方式：

    • 将小动物指派到赶海区域后，它会按一定速率自动捕获海岸生物；

    • 玩家每日登录收取收获箱即可，类似放置游戏的收菜循环。

  • 效率上限：自动捕获速率有上限，确保拿满奖励仍需玩家在活动周期内保持参与，而非首日完全挂机。

晚餐
#

目的：以"今日烹饪→明日增益"制造每日期待感，同时提供社交协作场景。

  • 烹饪规则：

    • 每日傍晚可用当日捕获的生物作为食材烹饪晚餐；

    • 不同食材组合对应不同料理，提供不同的次日增益（例如，效率提升、某类生物捕获率提升）；

    • 特定料理会触发小动物的奇遇。

  • 社交分享：

    • 邀请好友共进晚餐，双方均获得增益；

    • 好友带来的食材可弥补自己缺少的，促进互助。

  • 用餐中：用餐时角色们会进行闲谈与吃饭动画（类似《天穗之咲稻姬》），营造悠闲的生活感。

  • 夏日特色料理：部分限定料理（如，刨冰、海鲜烧烤等）仅在活动中出现，随代币积累、奇遇等逐渐解锁。

奇遇
#

目的：以条件触发的专属剧情激发"想集齐所有故事"的收集欲；并让活动有更多情感记忆点。

  • 触发条件：小动物+特定条件（捕获特定数量的某个海岸生物、晚餐制作某料理等）；

    • 例如：

      • 邀请了猫 + 累计捕获10个海贝 → 触发"贝壳收藏”；

      • 晚餐烹饪了贝壳汤 + 邀请了狗 → 触发"狗与海"。

    • 可以从对话中获得条件的提示；

  • 内容形式：

    • 1-2分钟的轻叙事小剧场（对话+少量演出），讲述小动物与赶海相关的个人故事；

    • 每个小动物有多段奇遇。

  • 奖励：每段奇遇解锁一件限定家具或服装（与故事主题相关），以及一张奇遇相片存入度假小屋相册。

  • 期待钩子：

    • 奇遇列表中未触发的条目显示为"？？？"，仅给出模糊提示，激发好奇心；

    • 部分奇遇所需条件跨周才能满足（如需要第3周才解锁的食材），形成持续探索动机；

    • 活动结束时若有未触发的奇遇，下次活动可以继续。

活动流程与节奏
#

  • 活动时长：4周

总览
#

阶段 时间 核心体验 解锁内容
第 1 周 第 1-7 天 学习基础赶海，建立"赶海→晚餐→增益→再赶海"循环，感受夏日海岛氛围 新海岸生物、第 1 只小动物、基础晚餐、度假小屋（初始）、夏日特色食谱
第 2 周 第 8-14 天 引入协作，小屋扩建，触发首批奇遇 协作生物、小屋 2 房间、烧烤食谱、社区目标开启
第 3 周 第 15-21 天 自动化成型，社交晚餐，奇遇集中触发 更多协作生物、房间解锁加速、海滩派对
第 4 周 第 22-28 天 收菜满足 + 奇遇收尾 + 终局高潮 奇遇最终阶段
活动后 — 度假小屋保留外观，小动物闲聊唤起记忆 —

第一周
#

目标
#

  • 让玩家学会基础赶海操作，建立"赶海——晚餐——增益——再赶海"的核心循环；

  • 感受夏日海岛氛围与轻松基调。

流程
#

  1. 活动开场，玩家乘船抵达赶海岛屿，NPC带入度假小屋，介绍小屋功能（烹饪、相册、房间等）；

  2. 傍晚触发首次晚餐烹饪引导，制作最简单的料理并获得次日增益；

  3. 第二天，邀请第一个小动物协作；

  4. 第二天开始新海岸生物逐日出现。

第二周
#

目标
#

  • 引入协作生物，体验与好友或小动物配合捕获的乐趣；

  • 房间逐渐解锁，更多小动物，开始学习按能力分配工作；

  • 触发首批奇遇，激发收集欲。

流程
#

  1. 协作生物出现，引导玩家尝试协作捕获；

  2. 新料理解锁；

  3. 首批奇遇条件可达成。

第三周
#

目标
#

  • 自动化基本成型，玩家从日常收集中解放，奇遇与社交玩法；

  • 奇遇集中触发期，相册逐渐丰满。

流程
#

  1. 自动捕获覆盖率足以应对日常需求；

  2. 多数奇遇在本周可触发；

  3. 小屋可扩建至满级，装饰自由度达到最高。

第四周
#

目标
#

  • 享受自动化带来的每天收菜满足感；

  • 制造活动后意犹未尽感。

流程
#

  1. 自动化满配，玩家几乎无需手动赶海即可拿满奖励；

  2. 奇遇进入最后阶段。

活动后
#

活动内容退场，度假小屋保留在岛屿上。小动物路过时触发赶海相关闲聊。
